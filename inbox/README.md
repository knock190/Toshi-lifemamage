# inbox

代表からの報告の受け口。1日1ファイル（`YYYY-MM-DD.md`）。

スマホからは Google ドキュメント「夜の報告（だんごカンパニー）」に書き足せばよい。秘書が毎朝 6:00 と 10:00 にここへ写す（`company/rules.md` 9 の「定期実行」参照）。`_drive-snapshot.md` は取り込み済みの内容の控え（秘書が管理）。
自由形式でよい。最後に調子を ◎○△ で添えると、秘書が翌日のタスク量を調整する（任意）。

1行目には、朝の報告の番号で結果を書く（○やった／×やらなかった／△一部だけ）。その下は自由に。

例：
```
1○ 2○ 3×
英語15分やった。ブログは無理だった。疲れた △
```
