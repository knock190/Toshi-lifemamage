# だんごカンパニー 台帳

代表（としやす）のやりたい事・目標を「事業」として同時に回すための台帳。
だんご（秘書・Ω・事業代表・作業者）はまず `company/rules.md` を読んでから動く。

```
CLAUDE.md          読み込み先の案内だけ（最小限）
company/rules.md   全体ルール
roles/             秘書・Ω・事業代表・作業者の役割
company/           会社全体（代表の状況・方向性・事業一覧・判断記録・後で決めること）
handoff/           役割どうしの受け渡し
inbox/             代表からの報告の受け口
businesses/<事業>/ 事業ごとの台帳
meetings/          週次・月次の会議記録
```

※ トークンやパスワードなどの秘密情報はこのリポジトリに書かない。
