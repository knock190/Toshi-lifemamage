# 事業フォルダの型

新規事業の立ち上げ（`company/rules.md` 8-2）で、Ωがこのフォルダを `businesses/<事業のフォルダ名>/` に写して使う。この README.md は写さない。
`<事業名>` を置き換え、各ファイルの書き手は `company/rules.md` §3 の「事業フォルダ」の表のとおり。

| ファイル | 書き手 | 立ち上げのときに書くこと |
|---|---|---|
| `inbox.md` | Ω | 立ち上げの連絡（受け入れの判断・方向性・先生：参加／なし） |
| `charter.md` | 事業代表 | ゴール・期限は案。状態は「承認待ち」 |
| `plan.md` | 事業代表 | マイルストーン |
| `orders.md` | 事業代表 | 最初の依頼「最初のタスクを作る」 |
| `status.md` | 事業代表 | 立ち上げの報告 |
| `tasks.md` | 作業者（事業代表が確定時に移す） | 最初のタスク |
| `log.md` | 作業者 | 書式だけ |
| `drafts/` `reviews/` | 作業者 | 空のまま |
