# 事業計画書：サプリ習慣化

| 項目 | 内容 |
|---|---|
| 事業名 | サプリ習慣化 |
| ゴール | サプリごとの週の目安を **毎週満たし続ける**（目安：クレアチン＝毎日・週7回、ほかのサプリ＝週4回）（2026-09-27 としやす決定） |
| 記録 | 連続記録（今の連続・最長）と、合計達成週数の両方を追う |
| なぜ | 脳の活性化（クレアチン）と体の調子を整えるため。筋トレのためではない（筋トレが狙いなのはプロテインくらい）。続いているかを見える化する |
| 開始 | 2026-09-28（月）＝1週目 |
| 期限 | なし（終わりのある目標ではなく、続けるもの。2026-09-27 としやす決定。前は「連続8週・11/22」） |
| かける時間 | ほぼなし（飲むことと記録のみ） |
| 状態 | 進行中（仕組みの試運転を兼ねる） |

- **連続**：今、続いているかを見る
- **合計**：1週崩れても積み上げは消えないと見えるので、やる気を保つ役

変更にはとしやすの承認が必要。
