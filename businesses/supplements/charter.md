# 事業計画書：サプリ習慣化

| 項目 | 内容 |
|---|---|
| 事業名 | サプリ習慣化 |
| ゴール | 全サプリで週の目標回数を **連続8週** 達成する |
| 記録 | 連続記録（今の連続・最長）と、合計達成週数の両方を追う |
| なぜ | この先の健康や筋トレの結果に影響するため。より良い結果を出すために、習慣化を見える化する |
| 開始 | 2026-09-28（月）＝1週目 |
| 期限の目安 | 2026-11-22。未達なら連続8週に届くまで続行 |
| かける時間 | ほぼなし（飲むことと記録のみ） |
| 状態 | 進行中（仕組みの試運転を兼ねる） |

- **連続**：習慣化できたかの判定に使う
- **合計**：1週崩れても積み上げは消えないと見えるので、やる気を保つ役

変更にはとしやすの承認が必要。
