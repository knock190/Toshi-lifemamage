## 全体の流れ
```
DNBをやる
```

## GAS のコード（としやすが貼る）
```javascript
// DNB記録：ショートカットから N と正解率を受け取り、1行足す
const TOKEN = 'ここに合言葉'; // 好きな文字に変える。Git やチャットには書かない

function doPost(e) {
  const p = JSON.parse(e.postData.contents);
  if (p.token !== TOKEN) return out({ ok: false, error: 'token' });
  const n = Number(p.n);
  const acc = Number(p.accuracy);
  if (!(n >= 1 && n <= 20) || !(acc >= 0 && acc <= 100)) {
    return out({ ok: false, error: 'value' });
  }
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  sheet.appendRow([new Date(), n, acc, p.memo || '']);
  return out({ ok: true });
}

function out(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}
```

## としやすの準備（1回だけ・20分ほど）
1. **GAS を貼る（10分）**
   - スプレッドシートを開く → 拡張機能 → Apps Script → 上のコードを貼る → `TOKEN` を好きな合言葉に変える
   - プロジェクトの設定でタイムゾーンを「(GMT+09:00) 東京」にする
   - 右上の「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」。実行するユーザー：自分／アクセスできるユーザー：全員 → デプロイ（初回は Google の許可画面が出る）
   - 出てきた「ウェブアプリの URL」を控える（合言葉と同じく Git やチャットには書かない）
2. **ショートカットを作る（10分）**
   1. 「数値を尋ねる」：質問「N（何個前）」
   2. 「数値を尋ねる」：質問「正解率（%）」
   3. 「URL の内容を取得」：URL＝ウェブアプリの URL／方法＝POST／本文＝JSON（`token`＝合言葉、`n`＝1つ目の数値、`accuracy`＝2つ目の数値）
   4. 「通知を表示」：「DNBを記録しました」
   - ホーム画面に置く。**おまけ**：「オートメーション → App → DNB アプリを閉じたとき → DNB記録を実行」にすると、押し忘れがなくなる

## 良いところ・弱いところ
- 良いところ：データはとしやすの Google に貯まる。毎日の入力はボタン1つ。サプリと同じ仕組みなので慣れている。オートメーションで押し忘れも減らせる
- 弱いところ：最初の準備が 20分ほどかかる。ウェブアプリの URL と合言葉を知られると誰でも書き込めるので、人に見せない
- **確かめていないこと**：
  - GAS のデプロイ画面の言葉は、Google の画面の変更で少し違うことがある
  - DNB アプリを閉じたときのオートメーションが、そのアプリで選べるか（iPhone で見てみないと分からない）
  - サプリのショートカットと GAS の作りは台帳に残っていないので、同じ作りかは分からない。サプリの GAS に足す形もありうるが、置き場所を読書に分けるため、別のスプレッドシートにする案にした
