#### 1章の要点ごとの長めの要約（2026-10-09 依頼票 2026-10-09-3）

**1. 幸福度は「科学的」に定義できる**
「幸福度」と聞くと、ふわっとして怪しく、スピリチュアルや根拠のない自己啓発の話に聞こえるかもしれない。だが近年の幸福学や神経科学の研究で、幸福感は脳内の化学物質がもたらすことが分かってきた。人が「幸せだ」と感じるとき、脳では特定のホルモンや神経伝達物質が出ている。この視点を持てば、あいまいだった「幸せ」を測ったり高めたりでき、具体的に理解して実践できるものになる。この章の定義は、2章以降のロードマップ全体の根っこになるので、理解できるまで読み込んでほしい、と著者は言う。

**2. 幸福度を決める4つの「幸せホルモン」**
幸福の感じ方は人それぞれで、1つの尺度では語り切れない。そこで本書は分かりやすさのために「幸せホルモン」を1つの視点として使う。厳密にはホルモンと神経伝達物質は別物だが、まとめてこう呼ぶ。幸福度が最大の状態とは、幸せホルモンが **バランスよく、最大量** 出ている状態。幸福に関わる物質は多いが、特に大事な4つ（ドーパミン・セロトニン・オキシトシン・βエンドルフィン）を取り上げ、それぞれの役割・出し方・バランスの取り方を順に見ていく。

- **ドーパミン**：目標を達成したときの喜びや快感を生み、人を行動へ駆り立てる。仕事で結果が出たとき、新しい挑戦をしたとき、「何か良いことがありそう」とワクワクしているときに出る。著者は新しい事業を立ち上げるときや目標を達成したときに強く感じ、「やった！」という達成感と次への意欲が湧くという。ただし衝動性も高めるので、追い求めすぎると依存的な行動（アルコール・ギャンブル）につながる。著者が余命宣告を受けるまで飲み会を週8回繰り返していたのも、ドーパミンに支配されていたからだと振り返っている
- **セロトニン**：睡眠ホルモンのメラトニンのもとになり、βエンドルフィンやドーパミンを抑えて心を安定させる。感情や攻撃性のコントロール、行動の柔軟さにも関わる。栄養と日光で作られるので、毎日決まった時間に起きる・日光を浴びる・バランスの取れた食事・適度な運動、という規則正しい生活が大事。ただしこれだけに偏ると、心は安定しているのに同じルーティンを淡々と回すだけになり、困ってはいないが前進している実感がない。不安や焦りは減るが挑戦する気が湧かず、「落ち着いているのに満たされない」感じが残る。だからセロトニンは **土台として整え**、他とのバランスを見る
- **オキシトシン**：不安を和らげ、共感や人への信頼を高める。家族や心を許せる相手・ペットとのスキンシップ、リラクゼーションの施術で出る＝温かいつながりと安心できる関係の中で生まれる。お金を稼ぐことに夢中だった頃の著者は表面的な人間関係ばかりだったが、事業を整理して教育事業に注力してから、受講生や仲間との信頼が深まり、落ち着いて安心して過ごせるようになった。鍵は「信頼関係を築くこと」と「安心して毎日を過ごすこと」。ただし安心が強すぎると居心地の良い所に留まり、挑戦しなくても満たされてしまう（仲間との時間は心地良いのに踏み出す力が湧かない、目標があいまいになり成長の実感が薄れる）。人生の土台を安定させるが、推進力にはなりにくい
- **βエンドルフィン**：ストレスがかかると出る、ストレスに打ち勝つための「脳内麻薬」。適切に出ればストレスが和らぎ、達成感や充実感が高まるので、何かを成し遂げるには必要。だが過剰だとうつ病や自殺のリスクが上がる、不安になりやすい、という研究がある。イメージは **アクセル**。踏み続ければどこかで事故が起き、セロトニンやオキシトシンを置き去りにして土台から崩れる。徹夜続きで「自分は無敵だ」と感じるのは回復ではなく、痛みや限界が麻痺しているだけ。それを数日〜数週間続けると、休もうとしても落ち着けず、何もしないと価値が下がる気がしてさらに負荷を足す、という「限界をごまかして走る → 壊れる」ループに入る。著者も睡眠を削り、親しくもない人と好きでもないお酒を朝まで飲む生活で過多になっていた。「幸福になるため」の仕事に切り替えてから自然に落ち着いた。大事なのは、自分の負荷を把握して自分で調整できることと、**無理を続けることを努力と勘違いしないこと。努力とは、壊れるまでアクセルを踏むことではなく、長く走れる状態を作ること**

**3. 幸せホルモンは「バランスを保ったまま最大量分泌させる」ことが重要**
一番大事なのは、バランスを保ったまま量を最大にすること。ドーパミンだけを追って仕事に没頭すればセロトニンとオキシトシンが足りず心身を崩し、βエンドルフィンが多すぎれば無理な生活になる。逆にセロトニンだけで規則正しく暮らしても、挑戦や達成感がなければ退屈で物足りない。オキシトシンを求めて人間関係ばかりに時間を使っても、成長や挑戦がなければ満足できない。βエンドルフィンとセロトニンのように一部トレードオフの関係もあるので、一番良いバランスを探しながら最大量を目指す。「仕事で達成感を得る時間」「規則正しい生活を保つ時間」「信頼できる人と過ごす時間」をすべて大切にする生き方が、科学的に見た「幸福度の高い人生」だという。

**4. 幸せホルモンのバランスが崩れた著者の例**
大学生でビジネスを始めた著者は「稼ぐこと」を最優先に走ってきた。売上が伸びる・事業が広がる・フォロワーが増えるたびに高揚したが長続きせず、すぐ次の刺激・数字・承認を求めた。ドーパミンとβエンドルフィンが多すぎ、セロトニンとオキシトシンが少ない状態だった。「すごいですね」「稼いでいますね」と言われるたびに自分の価値を確かめる日々で、数字や他人の承認でドーパミンが出るようになると、**達成の基準が他人軸** になる。いつも評価・比較・嫉妬に悩み、「稼げない自分に価値はあるのか」「数字で示せない貢献に意味はあるのか」という問いに縛られた。厄介なのは、心が安定しないのに止まれないこと。不安をかき消すためにβエンドルフィンの力で働き、満たされず夜は飲み会で刺激を求め、食事も荒れて過食気味で太った。「働いて、稼いで、褒められて、飲んで、食べて、また働く」のループで、どれだけ手に入れても満たされなかった。同じ失敗をしないよう、次章から4つが偏らない生活の設計を説明する、とつなげている。

**5. ［番外編］マズローの欲求階層説**
幸せホルモン以外のモデルでも幸福度は説明できる。人の欲求が過不足なく満たされると、幸せホルモンも偏らずに出る。その欲求の構造を整理したのが、心理学者アブラハム・マズローの5段階のピラミッド＝下から ①生理的欲求（食事・睡眠）②安全欲求（安全な環境・経済的安定）③社会的欲求（所属・愛情）④承認欲求（評価・尊敬）⑤自己実現欲求（自分の可能性の実現）。下が満たされて初めて上を求める（食事にも困る状態で評価や自己実現は考えられない）。①〜④は「足りないものを満たす」のがやる気の源の **欠乏動機**、⑤は能力を活かしてさらに成長したい **成長動機**。真の幸福には両方が要る（お金があっても人間関係が薄ければ満たされず、関係が良くても経済的不安があれば安心できない）。ホルモンとは、生理的 → セロトニン／安全・社会的 → オキシトシン／承認 → ドーパミン／自己実現への負荷 → βエンドルフィン、ときれいに対応する。土台と安心が弱いまま承認だけ追うとドーパミンが暴走し、刺激に慣れて「もっと欲しい」が止まらなくなる。著者は年商10億円で承認はある程度満たされたが、持ち上げられて表面的な関係に疲れ、本当にやりたいことを追えず、社会的欲求と自己実現が欠けたドーパミン過多だった。教育に注力し、受講生や社内スタッフとの関係づくりを意識してから、真の幸福を感じられるようになった。

**6. ［番外編］幸福度をパラメータで考える**
現実の人生は「下から順に」ではなく揺れ動く。一度満たした下の欲求も、上に進んだあとに崩れていることがある。著者も承認・成果では満たされていたのに、余命宣告で一気に「健康」の土台が揺らいだ。そこで5段階を「段階」ではなく、**今それぞれがどれくらい満たされているか** をパラメータで見える化する。項目は **健康（生理的）・金（安全）・人間関係（社会的）・成果（承認）・やりがい（自己実現）** の5つ。レーダーチャートにすると五角形になり、**面積が大きいほど幸福度が高い**。お金だけ突出しても、ほかが低ければ歪んだ形で面積は小さい（お金はあるが時間がない・関係が薄い・健康を損なう・やりがいがない）。どれか1つを極端に伸ばすのではなく、すべてをバランスよく高める。お金のために健康を犠牲にしたり、やりがいのために人間関係をおろそかにすると、結果的に幸福度は下がる。これもホルモンと対応し、健康や時間の余白 → セロトニン、人間関係 → オキシトシン、やりがい → ドーパミン、挑戦の適度な負荷 → βエンドルフィン。本書は幸せホルモンを中心に説明するが、自分が理解しやすいモデルで捉えてよい。

**7. 幸福度を高めるために持っておくべき思考：「他者への価値提供」を重んじる**
余命宣告をきっかけに著者が気づいたのは、ホルモンのバランスを整える一番効果的な方法は、「他者の役に立つ」ことに価値を感じ、**ドーパミンの発生地点を変える** ことだという点。4つを同時にバランスよく出せる行動は少ないが、価値提供は4つすべてに効く。これが本の結論に近い部分。お金・他人との比較・承認をドーパミンの発生地点にしてはいけない。そうするとドーパミンとβエンドルフィンが多すぎて無茶な働き方になり、セロトニンとオキシトシンが不足する。例えば「フォロワー数が多い＝すごい」だと、売上に影響がなくても抜かれただけで深く落ち込む（分かりやすい指標ゆえの弊害）。「売上が多いほどすごい」だと売上に執着し、「何がやりたいか」より「何が稼げるか」で考えるようになるが、熱量がないまま売上だけを追って働き続けることはできない（燃え尽きて病んだ周りの経営者と著者自身の実感）。一方、価値提供を基準にすると、①「あの人より稼ぎたい」「もっといいねが欲しい」という相対的な指標で動かなくなり、人と比べて不安にならず自分のペースで進める ②役に立てた・喜んでもらえた実感がドーパミンになり、βエンドルフィンも適量出る ③価値を通じた信頼やつながりでオキシトシンが出る ④無茶をしないのでセロトニンも出る。価値提供は「頑張るほど壊れる構造」ではなく **「続けるほど整う構造」** で、幸福は単発の高揚ではなく持続する安定として積み上がり、4つが互いの欠点を補い合う。これは新しい発見ではなく、論語の「徳」や近江商人の「三方よし（売り手よし・買い手よし・世間よし）」と同じ。昔の人は経験則で知っていて、今は脳科学で理由を説明できるようになっただけ。価値提供は道徳的に美しいだけでなく、**最も合理的で再現性の高い戦略** で、4つを整える中心軸は結局「人の役に立つ」に収束する。

**8. 「幸福度」を軽視した例と推奨する働き方**
価値提供を軽んじ、お金や承認に偏ると、バランスが崩れて悪い影響が出る。著者の知人の「お金持ち」2人の例。1人目は、高級車のコレクションが趣味の IT 経営者。山の中に専用のガレージハウスがあり、10台以上の名車が並ぶ夢のような空間。だが遊びに来る人はほとんどおらず、車の話で盛り上がる仲間もいない。売上も利益も時間も自由も手にしているのに、1台ずつ眺める姿はどこか寂しそうだった。人が幸福を感じるのに必要なのは、お金やコレクションではなく信頼やつながりの温かみ。価値提供を軸に関係を育てていれば、ガレージは「孤独に眺める展示室」ではなく「仲間が集まる遊び場」になり、オキシトシンが生まれていたはず。2人目は、SNS で著者に粘着してきたアンチ。思い切って会うと、年収も肩書きも立派な成功した経営者だった。理由を聞くと、自分より若い著者が稼いでいるのが悔しく「俺のほうが上だ」と証明したかった、と。自分の価値を比較でしか確かめられないと、相手を下げるしか自分を保てず、どれだけ稼いでも心は落ち着かない。「不幸なお金持ち」にならないために、ドーパミンの発生地点を比較や承認から価値提供へ変え、表面的な数字に囚われず誰かに価値を届けることを大事にする。**1万人と浅く関わるより、100人に「あなたのおかげでめっちゃ人生が変わりました」と言われる関わり方** のほうが、オキシトシンが多く出て幸福度が高まる。

**9. 幸福度を高めるべき進化的観点からの理由**
「他人のために働こう」は綺麗事だと感じる人に向けて、進化から根拠を示す。人は他の動物よりずっと長い期間、親や仲間の助けなしには生きられない。その長い依存期間を生き延びるため、脳は人とつながっていたいと感じるように進化した。さらに協力が生存に有利だったので「人の役に立つ者が生き残りやすい」という自然選択が働き、「人の役に立つ＝快い」「感謝される＝嬉しい」が本能に組み込まれた。食料を独り占めする人より分け合う人のほうが信頼され、困ったときに助けてもらえ、集団も安定する。そうした経験の積み重ねで、脳は役に立つ行動に報酬を与えるようになった。だから価値提供は、ドーパミンだけでなくオキシトシン（信頼・つながり）とセロトニン（安定）も促し、適度な負荷の挑戦ではβエンドルフィン（充実）も働く。日本の「縁起がいい」も、本来は仏教で「物事はさまざまな因縁（条件やつながり）で成り立つ」という意味で、運の良さは良い縁（つながり）から生まれると、昔の人は肌感覚で知っていた。逆に孤立したり役に立たない生き方は脳の進化の原理に反し、虚しさや不安として表れる。

**10. 章のまとめ**
本書では、幸福度を「4つのホルモンのバランスと量」と定義し、それが最適な状態を幸福とする。そのために重要なのが「他者への価値提供」を重んじること。次の章からは、幸福度を高めつつ稼げるようになる方法、「お金あり・幸せ」のエリアへ行く方法を説明する。この章は基本になる大事な考え方なので、何度も読み返して理解してほしい、と締めている。
