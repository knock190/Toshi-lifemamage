# 事業計画書：読書

| 項目 | 内容 |
|---|---|
| 事業名 | 読書 |
| ゴール | **読む冊数と、行動に移した数の両方** を積み上げる。目標は、本のドキュメント化を **月2冊**、アクションプランの実行を **週1件（月4件）**（2026-09-23 としやす承認） |
| 記録 | 読んだ冊数（月ごと・合計）と、アクションプランの実行数（週ごと・合計）の両方を追う |
| なぜ | 読んだ本をドキュメントとして残し、アクションプランを実行して行動につなげたい。相談したとき、読んだ本をもとに先生としてアドバイスしてほしい |
| 開始 | 2026-09-24。まず読み終えた本からドキュメント化する |
| 見直し | 2026-12-27（3か月）。11月の入社で使える時間が変わるので、そこでも一度見直す |
| かける時間 | 「読む」に1日30分。アクションプランの毎日の習慣（2026-09-25 から：筆記開示8分・DNB15分）は30分の外で足す（合計 約53分／日。2026-09-25 としやす承認。前は「1日30分にアクションプランの実行を含む」） |
| 状態 | 進行中（立ち上げ） |

## 役割は3つ
1. **記録**：本ごとにフォルダ（`books/<書名>/`）を作り、本の要点と、チャットでやったワークの結果を残す。ワークの結果はとしやす専用の記録として原文のまま残す
2. **実行**：本ごとにアクションプランを作り、1回15〜60分のタスクにして実行する
3. **先生の土台**：本棚とワーク結果を育て、事業をまたぐ役割の先生（`roles/teacher.md`）が、としやすの相談や他の事業の進め方に使えるようにする。相談の受け口は読書事業（`plan.md` の「先生への相談の受け口」）

変更にはとしやすの承認が必要。
