# 事業計画書：読書

| 項目 | 内容 |
|---|---|
| 事業名 | 読書 |
| ゴール | **読む冊数と、行動に移した数の両方** を積み上げる。目標は、本のドキュメント化を **月2冊**、アクションプランの実行を **週1件（月4件）**（2026-09-23 代表承認） |
| 記録 | 読んだ冊数（月ごと・合計）と、アクションプランの実行数（週ごと・合計）の両方を追う |
| なぜ | 読んだ本をドキュメントとして残し、アクションプランを実行して行動につなげたい。相談したとき、読んだ本をもとに先生としてアドバイスしてほしい |
| 開始 | 2026-09-24。まず読み終えた本からドキュメント化する |
| 見直し | 2026-12-27（3か月）。11月の入社で使える時間が変わるので、そこでも一度見直す |
| かける時間 | 1日30分（週3.5時間）。読む時間とアクションプランの実行を含む |
| 状態 | 進行中（立ち上げ） |

## 役割は3つ
1. **記録**：本ごとにフォルダ（`books/<書名>/`）を作り、本の要点と、チャットでやったワークの結果を残す。ワークの結果は代表専用の記録として原文のまま残す
2. **実行**：本ごとにアクションプランを作り、1回15〜60分のタスクにして実行する
3. **先生**：代表から相談を受けたら、同じジャンルの読んだ本と、代表自身の過去のワーク結果をもとにアドバイスする（`plan.md` の「先生の答え方」）

変更には代表の承認が必要。
