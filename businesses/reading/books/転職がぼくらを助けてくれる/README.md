### はじめに 圧倒的にコスパがいいのは出世より「転職」（2026-10-04 取り込み）

#### 概要
- この本は、新卒採用で第一志望の会社に入れなかった人、なんとなくモヤモヤを抱えて今の会社で働いている人のための、人生を変える「マニュアル」
- 著者は偏差値40以下の高校を卒業後、月給16万円の自動車部品会社に就職。3回の「転職という武器」で世界最大級のコンサルティング・ファームのコンサルタントになり、30歳で年収1000万円を超えた。そこまでにやったことの全てを、誰でも再現できる方法論にした

#### 要点
1. **努力・地頭・運ではなく、「転職」という誰にでも使える武器**
   - このやり方で、外資系コンサルティング・ファーム、大手外資系IT企業、日系大手メーカーなどに内定をもらった（ごく一部の会社には通用しない。それは後で書く）
   - 経歴を話すと「すごい大逆転！相当努力されたんですね」「もともと地頭がよかったんですね」の2種類が返ってくるが、どちらにも「運がよかったね、自分には関係ない」というニュアンスがある。でも、がむしゃらな努力・地頭のよさ・運の結果ではない。「転職」を最大限利用し、「あたり前の結果」を手に入れただけ
   - 「誰にでもできるのに、みんなが実践していないこと」を知るだけで、入りたい会社に就職し、やりたい仕事をして、お金の余裕もでき、今より納得した人生を送れる
   - 読む必要がない人：東大卒・新卒で第一志望の大手・幹部候補として出世している人。商才があり副業で儲けている人。読んでほしい人：親ガチャ・新卒ガチャ・環境ガチャで人生が決められていると思い込み、絶望を抱えている人。自分が「トップエリート」に入っていない現実に直面し始めている人
2. **日本の転職市場は「実績」だけが評価されるラッキーな場所**
   - やりたい仕事をして年収を上げるには、出世より「転職」が圧倒的にコスパがいい。根拠は日本の特殊な労働市場。気づいたきっかけは、新卒の会社の「タイ工場立ち上げ」で、タイ人の同僚が「今とは別の仕事がしたいから、大学に通っている」と言ったこと
   - **ジョブ型雇用**（主に欧米）：仕事に人を割り当てる。職務記述書（ジョブディスクリプション）で業務や範囲を決めて働く。アカデミックな専門知識とジョブが結び付き、専門職は高学歴（大学院出身者）が一般的
   - **メンバーシップ型雇用**（日本の主流）：ジョブ型を導入している会社は12%程度（株式会社リクルートキャリア「『ジョブ型雇用』に関する人事担当者対象調査2020」）。新卒一括採用で「総合職」を確保し、研修を経て配属が決まる。ジョブローテーションが典型
   - 日本は新卒一括採用では「学歴」が超重要視されるが、転職市場に出た途端「実績」を見られる。学歴や修士号の有無、専門は参考にされるくらい。これが、東大卒がゴロゴロしているコンサル業界に高卒の著者が入れたカラクリ。この社会構造をうまく利用しない手はない
3. **実践者だから書けた「非エリートの戦略」のマニュアル**
   - これまでの転職本と違い、「非エリートの戦略」に徹底的にこだわった。例：定番の「キャリアの一貫性を大事にしよう」は、志望業界と自分の間に一貫性がなかった著者には役立たなかった。こうしたキレイごとは排除した
   - 常識と本書の違い：自己分析をしよう → **自己分析を元に会社選びをしてはいけない**／コンサルやITはエリート → **学歴がなくてもコンサルやITは狙える**／社内MVPをアピールせよ → **地味な仕事でも転職の実績になる**
   - このメソッドを **「わらしべ転職」** と名付けた。昔話「わらしべ長者」のように、3回の転職で少しずつステップアップした。最初から狙いがあったわけではなく、目の前のわらをつかんでいたら遠くに来ていた
   - 18〜31歳の歩みを振り返ると、キャリアの選択の「よかったこと」「悪かったこと」「意味があったこと」「ムダだったこと」が分かる。それをもとに「予備知識がなくても誰でも使えて、再現性のある」マニュアルにした。どんな業界・職種にも応用がきく
   - 自動車業界ではマニュアルが超重要視されていて、著者はそれを日々改善するのが大好きだった。マニュアルを読めば新人でも期間工でも質の高い製品がつくれるように、本書を1冊読めば誰でも転職という武器を使いこなせる
4. **「わらしべ転職」年表（図。前半だけ）**
   - 2008年4月〜2012年7月（18〜22歳）：株式会社松田電機工業所（自動車用スイッチ製造）。生産技術担当。自動車部品の生産準備、既存生産品の生産性・品質改善、自社開発製品のプロモーション企画

1. **「転職活動」と「転職準備」は車の両輪**

2. **転職のゴールを見失ったら「3択」から選べ**
   - 本書のゴールは「人生は、どうせこんなもの」という状態から抜け出して「キャリアの選択肢を増やす」こと。行く先は人によって違い、「自分が納得するゴール」は自分で決める必要がある

   - 本心がわかっていない人には「ゴールは3択」と答えている：**①年収を上げる ②やりたいことをやる ③ワークライフバランスを優先する**。どこまで上げたいか・ライフの割合はどれくらいかなどグラデーションはあるが、あらゆる転職の選択肢はこの3つに集約できる。著者は **第1優先が「やりたいことをやる」、第2優先が「年収を上げる」**

### 第3章 転職エージェント ―「転職エージェント」の戦略：人生相談するより「情報」を聞き出せ（2026-10-05 取り込み）

**概要**：転職エージェントは企業から報酬（採用者の年収の約30%が相場）をもらうビジネスなので、人生相談の相手（カウンセラー）ではない。無料で使えるメリットを逆手にとり、「より高い年収で決まれば互いに得する」ビジネスパートナーとして、プロだけが知る「クローズド情報」と給与交渉を引き出す。

**要点**（目次の番号どおり）

- 31. 「あなたには難しいですよ」のアドバイスは完全スルー：エージェントは「今の会社・今の年収を基準に」相場感で受かりそうな会社を勧める＝1章で避けるべき「現状にとらわれる」やり方。著者は高卒（「学歴：4年制大学卒業以上」の応募条件が多い）で「コンサルを受けたい」と言うと「ほぼ100%無理ですよ」。常識的なアドバイスは全部無視する（受けて落ちれば学びがある）。特定の担当者は決めず、必要なときに必要な人に相談。迷ったら大手エージェント（求人の幅が広い）。「優秀なエージェント＝受からせてくれるエージェント」ではない
- 32. プロだけが知っている「クローズド情報」を手に入れる：エージェントは絶対に利用する。価値は貴重な情報。自分から取りに行かないと教えてもらえない。4つ＝入社したい業界・企業の採用状況／転職成功した人のスキル・経歴／面接（質問内容・判断基準）／受かった人の実際の年収（同じポジションの最高額）。働き方（リモート・育休の実績など）も聞いておく

- 34. 【情報②】転職成功した人のスキル・経歴：大手エージェントは自社の人材データベース（個人は見られない）を持つ。受かった人のレベルが分かれば、足りないものも分かる。質問例＝その業界の人の前職の「同じ業界」と「違う業界」の比率／違う業界の例／中途採用組で「未経験」の人はいるか・割合／中途採用で入った人の前職・最低の学歴。LinkedIn・Wantedly・YOUTRUST などの SNS は個人でも見られるが、エージェントに頼むほうが確実
- 35. 【情報③】面接（質問内容、判断基準）：過去の面接で誰が受かり誰が落ちたかを知っている。質問例＝どんな採用試験か／事前対策は必要か／面接は何回か／質問内容／過去に落ちた人は何が理由だったか。著者は落ちた企業の理由も必ず確認する（学歴のように変えられないなら次へ、スキル不足なら2回目までに積み上げる）
- 36. 【情報④】受かった人の実際の年収（同じポジションの最高額）：転職サイトの年収の例は100万円単位でばらつく。エージェントは受け取れる年収の「ギリギリのライン」を知っている。入社するポジション（等級）と給与テーブル（上がるか・横ばいか・年功序列か）も聞く。質問例＝希望するポジションの入社時の年収／ひとつ上のポジションの年収／給与交渉の余地

### 第4章 実績づくり ―「実績づくり」の戦略：出世のためより「転職を前提」に働け（2026-10-06 取り込み）

**概要**：実績やスキルは一朝一夕には手に入らない。「いつ転職しても大丈夫な自分」に近づくために日々の仕事をする。「いつか辞めるから適当でいい」ではなく、「今の会社で出世するために働く」とも違う働き方。社内MVPを狙わず、「他の人がやらない仕事」（会社の儲けに直結するのに地味で、社内評価につながりにくい仕事）を小さく始めて、思考のプロセスを言語化し、人間関係を味方にして、実績を積む。

**要点**（目次の番号どおり）
- （冒頭）「出世のために働く」と「転職を前提に働く」の違いをまとめた図が本にある（ドキュメントには入っていない）。どちらも成果を出すが、やり方が全く違う
- 41. 社内MVPではなく「他の人がやらない仕事」を狙え：MVPを重視しない理由は2つ＝①コスパが悪い（学歴や新卒採用で1位でなかった人が、また仕事のレースで1位を狙うのは結果が見えている）②転職市場ではMVPは各社に1人いて希少でなくなる（県大会で1位でも全国大会ならライバルだらけ）。「ナンバーワンではなくオンリーワン」。花形部署・人気プロジェクトに興味はなく、前職の経験を生かせる評価されやすいプロジェクトだけを選んだ
- 42. 【他の人がやらない仕事①】社内の評価＝転職に役立つ実績ではない：「他の人がやらない仕事」＝会社の儲けに直結するのに、地味で社内の評価につながりにくい仕事。おすすめは「半径3メートル以内」のルールや仕組みを変えること。例＝書類フォーマットの修正（抜け漏れが多発していたので枠を細かく分かりやすく）／組立工程のシミュレーション図面を2次元から3次元へ（上司に提案して導入）。どちらも専門知識のほとんどない21歳で気づけたが、みんな興味がなく放置されていた。いい結果が出たらすぐ社内に共有する

### 第5章 身だしなみ ―「身だしなみ」の戦略：生まれつきの容姿より圧倒的な「清潔感」（2026-10-06 取り込み。53〜62 は朝、63〜66 はチャットで）

### 終章 最後の壁、「メンタルブロック」を解く（2026-10-06 取り込み）

**概要**：転職活動・転職準備のやり方を知っても、最後に「どうせ自分なんて……」というメンタルブロックが立ちはだかる。壁は自分のなかにある。学歴などの前提条件がどうあれ思い込みは起きる。長年積み重なった「思考の癖の集大成」なので、猫背を直すトレーニングのように、少しずつ「思い込みを外す練習」を繰り返す。練習は4つ＝「なぜ？」と問う／応募条件を無視する／落ちても気にしない／どうしてもダメならあきらめる。

**要点**（目次の番号どおり）
- 67. メンタルブロックを解くには「反復練習」が必要：転職の相談に来る人（いい大学を出た人ばかり）でも、「まだ今の自分には早い」と書類すら送らない、「学歴が低いから無理ですよね？」「中小企業の職歴しかないからキツい」と、1章の会社選びのはるか前で「バッターボックスにすら立っていない」人が多い。前向きな人でも自分の手で枠を狭め「やらない理由」をつくってしまう。解けるのは自分だけ。意志があってもすぐには変えられないので、繰り返しトレーニングする（途中で痛みが出ても、無理をせず継続）
- 68. 【メンタルブロック解除①】「なぜ？」と問いかける練習：メンタルブロックは「無意識」なので、まず自覚する。二の足を踏んでいると気づいたら、自分に「なぜ？」と問い直す（トヨタ発祥の「なぜなぜ分析」から発想）。例＝問い「なぜコンサルティング・ファームを受けないの？」→答え「学歴が足りていないから」→気づき「高学歴でない」ことと「受けない」ことはつながらない／問い「なぜ大手自動車メーカーを受けないの？」→答え「自動車部品メーカーから受かった人を知らないから」→気づき「受かった人を知らない」ことと「受けない」ことはつながらない。答えをよく見ると単なる思い込みだと気づける。問いかけた結果「受けない」と決めてもよい（「この IT スキルが必要だから1年は勉強にあてる」も前進）。根拠を持って撤退することと、思い込みでやめることは大きく違い、その2つを分けられるのがこの練習のよいところ
- 69. 【メンタルブロック解除②】「応募条件」を無視する練習：求人票を見てあきらめるのもメンタルブロック。著者はほとんどの求人票の「大学卒業以上」に当てはまらなかったが、条件を無視し続けたから今がある。まず応募条件を一切無視して求人票を眺める練習をすると、「この範囲から選ぼう」と思い込んでいたことに気づき、考えていなかった会社・なりたかった職種・新卒のときに行きたかった業界が目に入ってくる
- 70. 【メンタルブロック解除③】書類選考で「落ちても気にしない」練習：落ちても失うものは特にない（二度と応募できなくなる・今の会社の評価が下がる・経験やスキルが減る・お金を取られる、どれもない）。書類を出しまくると平均7〜8割落ちるが、慣れると「受からなければならない」が解ける。著者はデロイトに3回目の書類選考で受かった。企業はそのとき必要な人材を募集しているので、一度落ちても次にプラスにもマイナスにもならない。受けなければ受からない。落ちた経験から「自分に足りないもの」に気づけ、エージェントに聞けば改善できるものかも分かる
- 71. 【メンタルブロック解除④】どうしてもダメなら「あきらめる」練習：「どうしても越えられない壁」もある。著者の場合＝大学受験（1社目に入った後、週末に半年ほど勉強したが興味がわかず、夢中で読めるモノづくりの資料に取り組むほうを選んだ→仕事に身が入った）と英語（スバルからの転職で外資系メーカーを考え、3カ月ほど勉強したが、ネイティブレベルを求められる場所は難しいと判断）。「メンタルブロック」と「やってからあきらめる」は決定的に違う。本気度・夢中になれるか・落ちて悔しいかは、やってみないと分からない。続けるのも、損切りするのも自由。「あれもダメだった」と分かるのはむしろいいことで、やってみて全部ダメということは絶対にない

**要点の要約**：最後の壁は自分のなかの「どうせ自分なんて」（無意識の思考の癖）。反復練習で少しずつ外す。①「なぜ？」と問い、答えと結論がつながるかを見る（根拠のある撤退と思い込みを分ける）②応募条件を無視して求人票を眺め、視野を広げる③落ちても失うものはないので、出し続けて慣れる（平均7〜8割落ちる）④やってみてダメならあきらめてよい。やる前にあきらめるのとは違う。
