### はじめに 圧倒的にコスパがいいのは出世より「転職」（2026-10-04 取り込み）

#### 概要
- この本は、新卒採用で第一志望の会社に入れなかった人、なんとなくモヤモヤを抱えて今の会社で働いている人のための、人生を変える「マニュアル」
- 著者は偏差値40以下の高校を卒業後、月給16万円の自動車部品会社に就職。3回の「転職という武器」で世界最大級のコンサルティング・ファームのコンサルタントになり、30歳で年収1000万円を超えた。そこまでにやったことの全てを、誰でも再現できる方法論にした

#### 要点
1. **努力・地頭・運ではなく、「転職」という誰にでも使える武器**
   - このやり方で、外資系コンサルティング・ファーム、大手外資系IT企業、日系大手メーカーなどに内定をもらった（ごく一部の会社には通用しない。それは後で書く）
   - 経歴を話すと「すごい大逆転！相当努力されたんですね」「もともと地頭がよかったんですね」の2種類が返ってくるが、どちらにも「運がよかったね、自分には関係ない」というニュアンスがある。でも、がむしゃらな努力・地頭のよさ・運の結果ではない。「転職」を最大限利用し、「あたり前の結果」を手に入れただけ
   - 「誰にでもできるのに、みんなが実践していないこと」を知るだけで、入りたい会社に就職し、やりたい仕事をして、お金の余裕もでき、今より納得した人生を送れる
   - 読む必要がない人：東大卒・新卒で第一志望の大手・幹部候補として出世している人。商才があり副業で儲けている人。読んでほしい人：親ガチャ・新卒ガチャ・環境ガチャで人生が決められていると思い込み、絶望を抱えている人。自分が「トップエリート」に入っていない現実に直面し始めている人
2. **日本の転職市場は「実績」だけが評価されるラッキーな場所**
   - やりたい仕事をして年収を上げるには、出世より「転職」が圧倒的にコスパがいい。根拠は日本の特殊な労働市場。気づいたきっかけは、新卒の会社の「タイ工場立ち上げ」で、タイ人の同僚が「今とは別の仕事がしたいから、大学に通っている」と言ったこと
   - **ジョブ型雇用**（主に欧米）：仕事に人を割り当てる。職務記述書（ジョブディスクリプション）で業務や範囲を決めて働く。アカデミックな専門知識とジョブが結び付き、専門職は高学歴（大学院出身者）が一般的
   - **メンバーシップ型雇用**（日本の主流）：ジョブ型を導入している会社は12%程度（株式会社リクルートキャリア「『ジョブ型雇用』に関する人事担当者対象調査2020」）。新卒一括採用で「総合職」を確保し、研修を経て配属が決まる。ジョブローテーションが典型
   - 日本は新卒一括採用では「学歴」が超重要視されるが、転職市場に出た途端「実績」を見られる。学歴や修士号の有無、専門は参考にされるくらい。これが、東大卒がゴロゴロしているコンサル業界に高卒の著者が入れたカラクリ。この社会構造をうまく利用しない手はない
3. **実践者だから書けた「非エリートの戦略」のマニュアル**
   - これまでの転職本と違い、「非エリートの戦略」に徹底的にこだわった。例：定番の「キャリアの一貫性を大事にしよう」は、志望業界と自分の間に一貫性がなかった著者には役立たなかった。こうしたキレイごとは排除した
   - 常識と本書の違い：自己分析をしよう → **自己分析を元に会社選びをしてはいけない**／コンサルやITはエリート → **学歴がなくてもコンサルやITは狙える**／社内MVPをアピールせよ → **地味な仕事でも転職の実績になる**
   - このメソッドを **「わらしべ転職」** と名付けた。昔話「わらしべ長者」のように、3回の転職で少しずつステップアップした。最初から狙いがあったわけではなく、目の前のわらをつかんでいたら遠くに来ていた
   - 18〜31歳の歩みを振り返ると、キャリアの選択の「よかったこと」「悪かったこと」「意味があったこと」「ムダだったこと」が分かる。それをもとに「予備知識がなくても誰でも使えて、再現性のある」マニュアルにした。どんな業界・職種にも応用がきく
   - 自動車業界ではマニュアルが超重要視されていて、著者はそれを日々改善するのが大好きだった。マニュアルを読めば新人でも期間工でも質の高い製品がつくれるように、本書を1冊読めば誰でも転職という武器を使いこなせる
4. **「わらしべ転職」年表（図。前半だけ）**
   - 2008年4月〜2012年7月（18〜22歳）：株式会社松田電機工業所（自動車用スイッチ製造）。生産技術担当。自動車部品の生産準備、既存生産品の生産性・品質改善、自社開発製品のプロモーション企画

- 本書の武器「わらしべ転職」の全体像の章。戦略は「会社選び」「書類選考・面接」「転職エージェント」「実績づくり」「身だしなみ」の5つで、第1〜5章で1つずつ説明する。5つは **「転職活動」と「転職準備」の2部構成** で、両輪として考える
- 本書のゴールは「人生は、どうせこんなもの」から抜け出して **「キャリアの選択肢を増やす」** こと。行く先は人によって違うので、何よりも先に自分の本心を知る。迷ったらゴールは **3択**（年収・やりたいこと・ワークライフバランス）
- エリートの世界で熱い「ヘッドハンティング」「リファラル採用」は扱わない。声がかかるのを待たず、自分から探しに行く

#### 要点
1. **「転職活動」と「転職準備」は車の両輪**
   - 5つの戦略
     - 転職活動：①【会社選び】適職を探すより「波」に乗れ／②【書類選考・面接】成果より「思考のプロセス」を語れ／③【転職エージェント】人生相談するより「情報」を聞き出せ
     - 転職準備：④【実績づくり】出世のためより「転職を前提」に働け／⑤【身だしなみ】生まれつきの容姿より圧倒的な「清潔感」
   - 通常の転職活動は「そろそろ会社辞めようかな……」と考え始めたときから始まり、「会社選び」→「書類選考・面接」→「内定」→「退職」と進む。退職までの期間を考えると、だいたい **3〜6カ月** が一般的
   - **9割の人** が、転職を意識するときにこの「転職活動」にだけ目を向けている
   - こうした「一時的に転職活動をする」やり方では、「職を変える」ことはできても、わらしべ転職で目指す **「新卒で入れなかったあの会社に入社する」** というゴールは達成できない
   - 本気で納得できる人生を生きたいなら、「転職活動」しか見えていない視野の狭さを矯正する。転職活動と転職準備を、影響し合う両輪として考える
   - 「転職活動」だけがうまくなってもあまり意味がない。日々の仕事のやり方が、そのまま「実績」として積み上がるから。転職活動中ではない時期にも「転職準備」を意識することが重要
2. **転職のゴールを見失ったら「3択」から選べ**
   - 本書のゴールは「人生は、どうせこんなもの」という状態から抜け出して「キャリアの選択肢を増やす」こと。行く先は人によって違い、「自分が納得するゴール」は自分で決める必要がある
   - ただしこれは正論。著者が Twitter などで転職の相談に乗ると、「自分の望みが複数あって、どれを優先したらいいかモヤモヤしている」「自分が本当にやりたいことがわからない」という悩みをよく聞く
   - さらによくないのは、悩みが言語化さえされず、本当の気持ちがわからないまま、やみくもに転職するケース。失敗例：「報酬でやる気が出るタイプだったのに、カリスマ社長に憧れて薄給の会社に転職してしまった」「外資系企業の現場でバリバリ仕事をしてやりがいを感じていたのに、日系企業の管理職にキャリアチェンジ。ゆったりした日本企業に合わず、結局メンタルを病んでしまった」
   - **何よりも先に、自分の本心を知る**。この優先順位を忘れない
   - 本心がわかっていない人には「ゴールは3択」と答えている：**①年収を上げる ②やりたいことをやる ③ワークライフバランスを優先する**。どこまで上げたいか・ライフの割合はどれくらいかなどグラデーションはあるが、あらゆる転職の選択肢はこの3つに集約できる。著者は **第1優先が「やりたいことをやる」、第2優先が「年収を上げる」**
   - 「3つとも大事で選べない」「2つの間で葛藤する」とき：**人の本音は逆接の接続詞のすぐあとに隠れている**。「でも」「だけど」のあとに出てくるのが本音。本気で何かを決断している場合、人は「でも」とはいわないから。1ミリでも引っかかるなら、押し殺さないほうが後悔しない
     - 例：「この仕事はやりがいもあるしチャレンジしてみたい。でも子どもがまだ小さくて手がかかるんだよな……」→ 優先は「仕事＜子ども」。本心ではワークライフバランスを優先したい
     - 例：「この仕事はずっと夢に見ていたけど、年収がな～」→ 心の底ではやりがいより年収が優先
   - 「やりたいことがわからない」人でも、こう考えれば何を優先すべきかがわかってくる
3. **「ヘッドハンティング」「リファラル採用」は無視せよ**
   - エリート人材の世界では「ヘッドハンティング」「リファラル採用」が熱いといわれている
     - ヘッドハンティング：いわゆる引き抜き。プロのヘッドハンターが「名指し」で優秀な人に声をかけて口説き落とす。伸びている業界ほど人材の奪い合いで、高額の報酬の提示や社長自らの口説きもある
     - リファラル採用：社員が知り合いを自分の会社に紹介する。会社には「信頼できる社員の紹介なら安心」というメリットがあり、離職にもつながりづらい。そのために「人脈」をつくったり、SNSで実績を「発信」したりする求職者もいる
   - 本書ではこうした転職方法は **一切扱わない**。理由は、著者自身が経験したことがないから、そして多くの人には関係ないから。エリートの戦略と「わらしべ転職」の戦略とでは、やることが根本的に違う。新卒で第一志望に入社できた人たちと今から同じことをしても勝てない
   - 「声がかかる」のは確かにかっこいいが、著者にはオファーは来なかった。だから **「採用の条件を緩和してでも、とにかく人が欲しい会社、タイミング」** を探し出して、自分で応募した。書類選考で何回も落ちても気にせず受け続けた。実際、20代のときは **デロイトに2回落ちている**
   - 運命の人は、いくら待っても来ない。でも、自分から探しに行くほうがずっと楽しい。自分の意志さえあれば、人生は新しく始められる

#### 要点の要約
- **両輪**：戦略は5つ。①会社選び ②書類選考・面接 ③転職エージェント＝「転職活動」、④実績づくり ⑤身だしなみ＝「転職準備」。9割の人は3〜6カ月の転職活動だけを見るが、それでは「新卒で入れなかったあの会社」には届かない。転職活動中でない時期にも、日々の仕事を実績として積み上げる（1）
- **3択**：何よりも先に本心を知る。ゴールは ①年収 ②やりたいこと ③ワークライフバランス の3択。選べないときは「でも」「だけど」のあとが本音。押し殺さない（2）
- **待たずに探す**：ヘッドハンティング・リファラル採用はエリートの戦略なので扱わない。「とにかく人が欲しい会社・タイミング」を自分で探して応募し、落ちても受け続ける（3）
