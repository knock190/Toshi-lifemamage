### はじめに 圧倒的にコスパがいいのは出世より「転職」（2026-10-04 取り込み）

#### 概要
- この本は、新卒採用で第一志望の会社に入れなかった人、なんとなくモヤモヤを抱えて今の会社で働いている人のための、人生を変える「マニュアル」
- 著者は偏差値40以下の高校を卒業後、月給16万円の自動車部品会社に就職。3回の「転職という武器」で世界最大級のコンサルティング・ファームのコンサルタントになり、30歳で年収1000万円を超えた。そこまでにやったことの全てを、誰でも再現できる方法論にした

#### 要点
1. **努力・地頭・運ではなく、「転職」という誰にでも使える武器**
   - このやり方で、外資系コンサルティング・ファーム、大手外資系IT企業、日系大手メーカーなどに内定をもらった（ごく一部の会社には通用しない。それは後で書く）
   - 経歴を話すと「すごい大逆転！相当努力されたんですね」「もともと地頭がよかったんですね」の2種類が返ってくるが、どちらにも「運がよかったね、自分には関係ない」というニュアンスがある。でも、がむしゃらな努力・地頭のよさ・運の結果ではない。「転職」を最大限利用し、「あたり前の結果」を手に入れただけ
   - 「誰にでもできるのに、みんなが実践していないこと」を知るだけで、入りたい会社に就職し、やりたい仕事をして、お金の余裕もでき、今より納得した人生を送れる
   - 読む必要がない人：東大卒・新卒で第一志望の大手・幹部候補として出世している人。商才があり副業で儲けている人。読んでほしい人：親ガチャ・新卒ガチャ・環境ガチャで人生が決められていると思い込み、絶望を抱えている人。自分が「トップエリート」に入っていない現実に直面し始めている人
2. **日本の転職市場は「実績」だけが評価されるラッキーな場所**
   - やりたい仕事をして年収を上げるには、出世より「転職」が圧倒的にコスパがいい。根拠は日本の特殊な労働市場。気づいたきっかけは、新卒の会社の「タイ工場立ち上げ」で、タイ人の同僚が「今とは別の仕事がしたいから、大学に通っている」と言ったこと
   - **ジョブ型雇用**（主に欧米）：仕事に人を割り当てる。職務記述書（ジョブディスクリプション）で業務や範囲を決めて働く。アカデミックな専門知識とジョブが結び付き、専門職は高学歴（大学院出身者）が一般的
   - **メンバーシップ型雇用**（日本の主流）：ジョブ型を導入している会社は12%程度（株式会社リクルートキャリア「『ジョブ型雇用』に関する人事担当者対象調査2020」）。新卒一括採用で「総合職」を確保し、研修を経て配属が決まる。ジョブローテーションが典型
   - 日本は新卒一括採用では「学歴」が超重要視されるが、転職市場に出た途端「実績」を見られる。学歴や修士号の有無、専門は参考にされるくらい。これが、東大卒がゴロゴロしているコンサル業界に高卒の著者が入れたカラクリ。この社会構造をうまく利用しない手はない
3. **実践者だから書けた「非エリートの戦略」のマニュアル**
   - これまでの転職本と違い、「非エリートの戦略」に徹底的にこだわった。例：定番の「キャリアの一貫性を大事にしよう」は、志望業界と自分の間に一貫性がなかった著者には役立たなかった。こうしたキレイごとは排除した
   - 常識と本書の違い：自己分析をしよう → **自己分析を元に会社選びをしてはいけない**／コンサルやITはエリート → **学歴がなくてもコンサルやITは狙える**／社内MVPをアピールせよ → **地味な仕事でも転職の実績になる**
   - このメソッドを **「わらしべ転職」** と名付けた。昔話「わらしべ長者」のように、3回の転職で少しずつステップアップした。最初から狙いがあったわけではなく、目の前のわらをつかんでいたら遠くに来ていた
   - 18〜31歳の歩みを振り返ると、キャリアの選択の「よかったこと」「悪かったこと」「意味があったこと」「ムダだったこと」が分かる。それをもとに「予備知識がなくても誰でも使えて、再現性のある」マニュアルにした。どんな業界・職種にも応用がきく
   - 自動車業界ではマニュアルが超重要視されていて、著者はそれを日々改善するのが大好きだった。マニュアルを読めば新人でも期間工でも質の高い製品がつくれるように、本書を1冊読めば誰でも転職という武器を使いこなせる
4. **「わらしべ転職」年表（図。前半だけ）**
   - 2008年4月〜2012年7月（18〜22歳）：株式会社松田電機工業所（自動車用スイッチ製造）。生産技術担当。自動車部品の生産準備、既存生産品の生産性・品質改善、自社開発製品のプロモーション企画

- 19. 【リサーチ②】企業側の「募集背景」を知る：会社の課題はざっくり「売上が伸びない」「コストが下がらない」。中途採用は売上を伸ばしたい場合が多い。募集背景は3パターン＝①「欠員」を補充する（ピンポイントの即戦力。「入ることで今まで通り回る」とアピール）／②「事業拡大」で人を増やす（1章の大量採用。多少条件が足りなくてもまず書類を出す）／③「新規事業立ち上げ」で経験者を採用する（必要なスキルに特化して伝える）

- 21. 【職務経歴書①】未経験の壁はスキルの「ひも付け」で突破する：棚卸しだけでは受からない。仕事を細かく分解する「詳細化」で、一見関係ない仕事の共通点を見つける。著者は自動車メーカー（自動車製造の理解・機械設計（3DCAD）・プロジェクト管理・社内外コミュニケーション・競合他社分析・市場動向調査・製品原価分析）とコンサル（経営分析・プレゼンテーションスキル・インタビューテクニック・プロジェクト管理・社内外コミュニケーション・競合他社分析・市場動向調査）を並べて、共通点を強調した
- 22. 【職務経歴書②】一貫性は「職種」ではなく「スキル」で通す：職種や業界をそろえる「表面的な一貫性」は不要。本質は「スキル・経験のひも付け」を言語化して伝えること。異業種からの転職は企業から「甘く見てもらえる」面もある（著者は同業種の1回目より異業種の2回目のほうが厳しく見られなかった）
- 23. 【職務経歴書③】自己PRには「STAR」を入れる：Situation（状況・背景・目標）／Task（課題・役割）／Action（具体的な行動・理由・工夫・軌道修正）／Result（結果・学んだこと）。特に大事なのはA。Aには自分が大変だったこと・苦労したエピソードを入れる（仕事のやり方が表れる）
- 24. 【職務経歴書④】数字は相手が想像しやすい「単位」で書く：数字を入れるだけでなく、すごさを実感してもらう。例：年間1500万円（仮の数字）の削減を「1台あたり100円削減」に変換すると、採用担当者が自社の台数で勝手に計算してくれる。「3人をマネジメントして合計3億円、達成率120%」より「一人あたりの売上を30%増加させました」
- 25. 【職務経歴書⑤】営業ではなくても「数字の実績」はつくれる：おすすめは「効率化」＝コスト削減による利益への貢献。「金銭的なコスト」と「時間的なコスト」。著者はスバルで別々の部署の同じ作業を一本化し、材料コストと人員が半分になった。営業利益率10%の会社でコスト100万円削減は1000万円の売上と同じインパクト。小さな改善も横展開すれば十分な実績
- 26. 面接は「自分をPRする場」ではない：著者の書類通過率は2〜3割、面接通過率は8割以上。成功の理由は「徹底的に相手に合わせているから」。面接は「企業側が求めている内容に沿って、答えを用意する」場（「パンが欲しい」と言われているのに白いご飯を勧める人が多い）。人と同じことを言っても受からない。面接官に「他の人ではなく自分を通す理由」をつくる
- 27. 【面接テクニック①】「質問を誘うエピソード」を話す：暗記して話さず、「自己PRしてください」「志望動機は？」のように話をコントロールできる場面で、「語られていない空白」があるエピソードを話す。空白があると相手が「なぜ？」と質問してくるので、用意したPRポイントに持ち込める。大きな話でなくてよく、「振り返って楽しかった仕事」（ラクだった仕事とは違い、壁や苦労があった仕事）につなげる。自慢話は避ける
- 28. 【面接テクニック②】相手の「課題」をさりげなく聞き出す：面接で最も重要なのは「相手の課題に対して、自分を雇えば解決できる」と伝えること。課題を聞き出せた時点で9割成功。「刺さった／刺さっていない」をその場で判断して深掘りし、刺さらなければ別の経験で「御社でも生かせるでしょうか？」と手を替えて聞く。「パンとご飯、どちらを召し上がりますか？」と聞いてから、特製サンドイッチやあんパンを出す
- 29. 【面接テクニック③】逆質問は「調べてわかること」を聞くな：NGは「御社で活躍しているのはどんな人ですか？」「今日の僕の面接、いかがでしたか？」「入社したら、どんなスキルが必要ですか？」。OKは応募条件の深掘り（例：語学力が必要とのことですが、日本人との会議も全部英語ですか？）や、非公開情報（「御社のクライアントの詳細について」）から「その課題を僕が解決できます」に導く質問
- 30. 【面接テクニック④】痛いところを突かれても「盛る」のは禁止：ウソは必ずバレ、入社しても「転職準備」の段階でつまずく。やっていないことは「将来できそうなこと」を伝える／少しズラして話す（TOEICが足りないとき、正直に認めたうえで「タイでの駐在経験があり日常会話やメールは英語で可能」）。足りないことに答える3点＝①「御社が求めているのはこれですよね」の確認②今、自分ができること③入社後、できそうなこと
- column 学歴は無理に塗り替えなくていい：中途採用では実績が重視されるので、学歴を更新するメリットはそんなにない。著者はスバルで働きながら2年間、東京理科大学の大学院（MOT・技術経営専攻）に通い、尊敬する先生に直接教わったのがよかった。国内MBAの多くは「専門実践教育訓練給付金」の対象で、2年以上の職歴があればハローワークで費用の70%（最大112万円）が返ってくる

**要点の要約**：書類も面接も「相手が求めていること」に合わせて、成果の数字ではなく「どう考え、どう工夫したか」を語る。書類は、①求人票を調べて募集背景を見極め、②ひも付けで未経験の壁を超え、③STARのAを厚く、④数字は相手が想像できる単位に変える。面接は、⑤空白のあるエピソードで質問を誘い、⑥相手の課題を聞き出し、⑦盛らずに「今できること・入社後できそうなこと」で答える。

### 第3章 転職エージェント ―「転職エージェント」の戦略：人生相談するより「情報」を聞き出せ（2026-10-05 取り込み）

**概要**：転職エージェントは企業から報酬（採用者の年収の約30%が相場）をもらうビジネスなので、人生相談の相手（カウンセラー）ではない。無料で使えるメリットを逆手にとり、「より高い年収で決まれば互いに得する」ビジネスパートナーとして、プロだけが知る「クローズド情報」と給与交渉を引き出す。

**要点**（目次の番号どおり）
- （冒頭）エージェントのビジネスモデル：企業から報酬をもらう（図が本にある。ドキュメントには入っていない）。年収500万円で働き始めたら企業から150万円の報酬。個人より企業を優先するのは当然。人生やキャリアの相談を「ゼロから」持ちかけることには反対
- 31. 「あなたには難しいですよ」のアドバイスは完全スルー：エージェントは「今の会社・今の年収を基準に」相場感で受かりそうな会社を勧める＝1章で避けるべき「現状にとらわれる」やり方。著者は高卒（「学歴：4年制大学卒業以上」の応募条件が多い）で「コンサルを受けたい」と言うと「ほぼ100%無理ですよ」。常識的なアドバイスは全部無視する（受けて落ちれば学びがある）。特定の担当者は決めず、必要なときに必要な人に相談。迷ったら大手エージェント（求人の幅が広い）。「優秀なエージェント＝受からせてくれるエージェント」ではない
- 32. プロだけが知っている「クローズド情報」を手に入れる：エージェントは絶対に利用する。価値は貴重な情報。自分から取りに行かないと教えてもらえない。4つ＝入社したい業界・企業の採用状況／転職成功した人のスキル・経歴／面接（質問内容・判断基準）／受かった人の実際の年収（同じポジションの最高額）。働き方（リモート・育休の実績など）も聞いておく
- 33. 【情報①】採用状況（拡大？縮小？中途採用はある？）：1章の3つのタイミングに当てはまるかを聞く。絞っているなら「数カ月後に波は来るか？」。数カ月後なら待ち、1年かかるなら今受ける（一度落ちたから二度目も受からないことはない）。エージェントは「今年度の採用予算」を把握。質問例＝今の大量採用の傾向は今後も続くか／どれくらい続くか／過去に中途採用の実績はあるか／幹部で中途採用組から出世した人はいるか
- 34. 【情報②】転職成功した人のスキル・経歴：大手エージェントは自社の人材データベース（個人は見られない）を持つ。受かった人のレベルが分かれば、足りないものも分かる。質問例＝その業界の人の前職の「同じ業界」と「違う業界」の比率／違う業界の例／中途採用組で「未経験」の人はいるか・割合／中途採用で入った人の前職・最低の学歴。LinkedIn・Wantedly・YOUTRUST などの SNS は個人でも見られるが、エージェントに頼むほうが確実
- 35. 【情報③】面接（質問内容、判断基準）：過去の面接で誰が受かり誰が落ちたかを知っている。質問例＝どんな採用試験か／事前対策は必要か／面接は何回か／質問内容／過去に落ちた人は何が理由だったか。著者は落ちた企業の理由も必ず確認する（学歴のように変えられないなら次へ、スキル不足なら2回目までに積み上げる）
- 36. 【情報④】受かった人の実際の年収（同じポジションの最高額）：転職サイトの年収の例は100万円単位でばらつく。エージェントは受け取れる年収の「ギリギリのライン」を知っている。入社するポジション（等級）と給与テーブル（上がるか・横ばいか・年功序列か）も聞く。質問例＝希望するポジションの入社時の年収／ひとつ上のポジションの年収／給与交渉の余地
- 37. 給与交渉は、必ずエージェントを挟め：エージェントの報酬は年収で上下するので、給与交渉がうまくいけば互いにうれしい。「いつ」＝内定をもらったあとのオファー面談のとき（採用フローが完了すると書き換えにくい）。内定までの面接ではお金の話は聞かれなければしない（金額の目安がなければ、エージェントに早めに希望年収を伝えておく）。「誰が」＝エージェントが企業と行い、本人が直属の上司になる人とは直接行わない
- 38. 【給与交渉①】「現状のまとめ」から始まる：希望には「根拠」が必要。まず源泉徴収票を集め、現状の給与の内訳を理解する。チェック点＝裁量労働制か・残業代が出るか（新しい職場が残業代込みなら上乗せを交渉）／福利厚生費（家賃補助・出張手当などがなければ給与に上乗せを交渉。手取りが増えるかを計算）／源泉徴収票に表れない部分（期中のポジション変更など。著者は表にして提出）
- 39. 【給与交渉②】「もし現職にいたら上がる分」も交渉する：各企業の給与テーブルで、年齢・経験・スキルからどの等級で入社するかがほぼ決まる。著者はPwCからデロイトへ、ほぼ同じ等級で、さらに「来年度も現職にいたら昇給する予定の金額」を上乗せしたいとエージェントに相談した。大手は年齢ごとの給与テーブルが明確で、大きく外れる金額は難しい
- 40. 内定後も「気楽に連絡できる仲」を継続せよ：転職が終わってもゆるくつながる（ニュース・採用増・もう一度のチャンスを気軽に聞ける）。エージェントにも実績・次の転職で頼られる可能性がある。「ゆるく」がポイントで、SNSの連絡先を交換する（メールは「お世話になっております」で連絡のハードルが上がる）

**要点の要約**：エージェントはカウンセラーではなく、情報と給与交渉を引き出すビジネスパートナー。①「あなたには難しい」は無視し、②採用状況・受かった人の経歴・面接・年収のクローズド情報を自分から取りに行き、③給与交渉は内定後のオファー面談で、エージェントを通し、「現状のまとめ」と「現職にいたら上がる分」を根拠に行い、④内定後もゆるくつながる。

**作業者の補足**
- 3章のドキュメントは文字起こしの崩れが大きい（「エージュント」→「エージェント」、「つ」→「ひ」など）。読める文章だけから書いた。図（エージェントのビジネスモデル）、質問例の一部（33の「具体的な質問」のチェックボックス）は崩れ・欠けがあり、読める分だけ書いた
- 「転職エージェントの5カ条」はドキュメントに入っていない
