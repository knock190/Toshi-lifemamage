### 全体（目次から）
- 流れ：悪い勉強法をやめる（1章）→ 基本の2つ（2章）→ 勉強前（3章）→ 勉強後（4章）→ 上級編（5章）→ 地頭を鍛える（6章）
- 軸は「アクティブラーニング」＝ 受け身ではなく、思い出す・自分の言葉にする勉強

### 1章 やってはいけない！7つの勉強法
- 学校で教わる勉強法の多くは科学的に効率が悪い。ケント州立大学（2013年）が200件超の実験データから「効率が悪い」と判定したのが次の7つ。共通点は「やった気になるだけで使える知識にならない」
  1. ハイライト・アンダーライン：線を引いた安心感で脳が満足して覚えない。線の所だけに目が行き、流れや理由がつかめない
  2. 語呂合わせ：記憶術としては使えるが、つながりや意味が抜けて応用が効かない（買い物リストくらいならよい）
  3. 要約：流れの理解・要点の抽出・まとめ直しを全部やる難しい作業で、失敗しやすく疲れる（コツは2章）
  4. 再読：受け身なので疑問が湧かず頭に入らない。文章をクイズの形にすると脳が興味を取り戻す
  5. 集中学習（1単元をまとめてやる）：1週間で大半を忘れる。知識どうしがつながるのは「緩和モード」（リラックスして考えがさまよう状態）（休み方は4章）
  6. 自分の学習スタイルに合わせる：数百万人分のデータで効果なし。効く勉強法に個人差はない
  7. 忘れる前に復習する：覚えているうちの復習は脳が「もう知っている」と判断して残らない。忘れかけたころに思い出すと、脳が大事な情報と判断して定着する
- 見分け方：「このやり方は受け身じゃないか？」と自分に聞く

### 2章 「超効率勉強法」の基本
- 使える勉強法に共通する1つのポイントは **アクティブラーニング**。授業中だけでなく、予習・復習・趣味・寝る前まで全部をアクティブにする（「アクティブすぎるほどのアクティブラーニング化」）
- 例：参考書をざっと1周見たあと、ページをバラバラにして順不同で解いた → 応用に強い・試験で慌てない・飽きない
- **① 想起（思い出す）＝記憶に効く**
  - クイズ化：再読より定着率が50〜70%上がる。1ページ（慣れたら見出しごと）読んだら本を閉じて思い出す。ノートは本を閉じて思い出しながら書く（声で吹き込むとさらによい）。テストは毎日、自分で問題を作る
  - 1章の悪い方法もクイズ化で生きる：再読は1ページごとに要点を思い出す／要約は忘れかけてから何も見ずに書き、本で答え合わせ
  - 分散学習：復習の間隔を少しずつ伸ばす。1〜2日後→7日後→16日後→35日後→62日後。ざっくり版は「2日後→2週間後→2か月後」
  - インターリービング：1回の勉強で複数の内容を混ぜる（翌日のテストで25%上、1か月後は差が約2倍）。ジャンルは3つまで・時間は等分・1回ごとに休憩（迷ったら90分勉強→20分休憩）
  - チャンク化：情報を意味のあるかたまりにまとめる。身につくと直感が働く。コツは重要度を1〜10点で付ける／複数の解法をセットで覚える／マインドマップでつながりを見つける
- **② 再言語化（自分の言葉にする）＝理解に効く**
  - 自己解説：「なぜ（WHY）」「どうやって（HOW）」を自問自答。答えを見て分かった気になる「流暢性の罠」を破る
  - メタ認知リーディング：下調べ→速読→再読（何が分からないか）→再々読（人に説明できるレベルでまとめる）。時間がなければ再読の質問と最後のまとめだけ。理解を深めた後のまとめには意味がある（1章の要約の答え）
  - ティーチング：教えるつもりで勉強すると思い出せる率が28%高い。アヒルのおもちゃに説明する／10歳の子に説明する（たとえ話と相手が知っている知識を使う）／仲間とサイコロで当てて説明し合う
  - イメージング：頭の中で賛成派と反対派に議論させる／「友だちならどう解く？」と考える（ソロモン・イメージング）／英文の主人公を「私」に置き換えて音読する
- まとめ：「どうしたらもっと簡単に・面白く覚えられるか」を工夫し続けること自体がアクティブラーニング

### 3章 勉強前の準備（2026-09-26 取り込み）

#### 概要
- 見出しは「結果を出したければ、準備に時間をかけろ」。2章のアクティブラーニングの効果を最大にする条件は **勉強前の準備**。準備をするかどうかで集中力・記憶力に2倍の差がつく。「本当の勉強は、準備の段階からすでに始まっている」
- 準備テクは7つ。①目的で動機を変える（1）②頭の土台を作る（2・3）③環境を整える（4・6・7）④使う資料と使い方を先に決める（5）

#### 要点
1. **自己超越目標を持つ**（テキサス大学）
   - 自己超越目標＝自分の身の丈を超えた大きな目的（「良い仕事につきたい」ではなく「恵まれない人を救う仕事につきたい」）
   - 高校生に「社会の問題点」と「その問題に学校の勉強をどう活かせるか」を考えさせた（約50分）→ スマホのゲームの時間が減り、数学・科学の勉強時間が2倍に増え、成績も上がった
   - なぜ：モチベーションの質が変わる。ボーナスやおこづかいで目的がお金に変わると、やりがいが下がる。「誰かの役に立つかも」という感覚が、つまらない勉強に意味を与える
   - やり方（勉強前の10分）：「世の中をもっと良くする方法はないか？」「いま勉強していることが、そのためにどう役立つか？」。身のまわりの小さな問題（満員電車・ポイ捨てなど）でよい。思いつかなければ「自分にとってもっとも大事なものは何か？」（人・モノ・信条でよい）
2. **知っていることを書き出す**（ハーバード大学）
   - 勉強の前に「これから覚えること」ではなく、「関係がありそうな、すでに知っていること」を全部書き出す。その方が新しい情報を理解しやすく、定着率も高い
   - 例：電気を学ぶ前に「電池」「冬のドアノブのビリッ」「カミナリ」を思い出してから参考書を読むと、つながって理解が進む
   - なぜ：記憶は古い情報（木の幹）に新しい知識（枝葉）を結びつけて覚える。つながらない知識には脳が反応しない
   - 著者のやり方：本を読む前に目次・参考文献・著者の略歴・グラフを見て、関係しそうな知識を思い出す。全部思い出さなくてよい。「頭の準備体操ぐらいの気持ち」
3. **好奇心を刺激する**（カリフォルニア大学・2014年）
   - 初めて見る人の顔写真を覚える実験。先にトリビアクイズ（「ウインナーとソーセージの違いは？」など）を出し、答えが出るまでの14秒で覚えたグループは、記憶テストの成績が2倍。翌日の再テストでも効果が残った
   - なぜ：好奇心で脳の報酬系が動き、隣の海馬（記憶）も活発になる。興味のない情報まで覚えやすくなる
   - やり方：勉強の前に、興味を持てるものに5分ほど触れる。**好奇心が長続きするもの** がよい（スマホゲームは短期的）。トリビア・未解決事件のミステリー・次の展開が読めない漫画・パズル系のゲーム
   - Point：毎日の勉強に「謎」の要素を加える
4. **音楽を正しく使う**
   - 勉強中のBGMは邪魔にしかならない（グラスゴー・カレドニアン大学）。テンポの速い曲／ゆったりした曲／環境音（話し声・車の音）／無音の4つの部屋で認知テスト → 成績が下がらなかったのは無音だけ。テンポが速いほど下がる
   - なぜ：「無関連音効果」。関係のない音のパターンを脳が処理しようとして負担が増える。歌詞のある曲は特に悪い。読書中のBGMも止める
   - BGMで勉強が進んだ気がするのは、気分が上がっただけ（ドーパミン・アドレナリン）で、脳の働きは上がっていない
   - **ミュージック・ウォームアップ・テクニック**（ウェールズ大学）：①勉強の10分前までに好きな曲を聴く ②音楽を止めて勉強を始める ③休憩中にまた好きな曲を聴く。著者はノイズキャンセリング・ヘッドホンで環境音も切っている（耳せんでもよい）
   - 例外：**自然音**（風・鳥・小川・コオロギ）は注意力を上げる。5分聴くとリラックスし、集中力テストの成績も上がった。ストレスの多い人ほど効く。自然音のアプリを入れて勉強中に流すとよい
   - Point：音楽を聴きながら勉強しない。「無音」か「自然音」の環境を作る
5. **戦略的リソース利用法**（スタンフォード大学）
   - リソース＝問題の解決に役立つ手段・データ・人間関係（学生なら教科書・参考書・学習サイト・先生・勉強ができる友人。ビジネスなら資料・データ・上司・人脈・ビジネス書）。どれをどう使うかを先に決める
   - 7ステップ：①目標設定（欲しい成績）②重要度測定（100点満点）③自信測定（100点満点）④問題推測（出そうな問題を2〜3問）⑤資料抽出（使えそうな箇所を最大15個。本1冊ではなく特定のページ・セクション）⑥理由判定（なぜ使えると思ったか）⑦使用法判定（使う順番・取り組み方。人のリソースも）
   - 1日15分の事前計画だけで成績が上がり、ストレスも大幅に下がった
   - ビジネス版：欲しい成果 → 重要度 → 自信 → 起きそうな問題・求められる成果 → 資料・データ・人脈・ビジネス書を最大15個 → 理由 → 使い方。問題点と解決までのロードマップ・優先順位が見える
6. **自然の力で集中力を倍にする**
   - イリノイ大学（2018年）：児童300人。週1回だけ自然の多い公園で授業したクラスは、10週間後に集中度が2倍。いつもの教室に戻っても1週間高いまま
   - 週1回で十分。近所の公園や河川敷を先に調べておく。自然音アプリや、机の上の小さな観葉植物でもよい
   - **裸足ウォーキング**（ノースフロリダ大学）：勉強の前に芝生の上を裸足で軽く走ると、シューズのグループよりワーキングメモリのテストが16%高い
   - **かわいい子猫・子犬の写真** を見ると集中力テストの成績が上がり、作業が正確になる。細かい注意力が要る場面ほど効く（細かい計算・歴史のディテール）
7. **ピアプレッシャーでやる気を出す**
   - ピアプレッシャー（仲間からの圧力）には悪玉（残業で帰れない等）と善玉（まわりががんばっているから自分も）がある
   - コロラド大学：4歳の子のマシュマロ実験で「ほかの子はがまんできたよ」と伝えると、がまんできる確率が2倍
   - やり方：熱心に勉強している人が多い場所（試験勉強の生徒が多い図書館、学生が集まるカフェ）へ行く。慣れた自宅では脳が「サボっても大丈夫」と考えがち
   - 勉強ができる友人を増やす。ハーバード大学：生産性の高い同僚の隣に座らせると作業効率が17%上がった。ネガティブな人は遠ざける
   - Point：意志の弱い人は同調圧力を上手に使う。「意識の高い人」の多い場所で勉強する

#### 要点の要約
- **勉強は始める前から始まっている。** 始める前の数分〜15分で、成果が大きく変わる
- **頭の準備**：目的を「誰かの役に立つ」まで広げ（1）、知っていることを書き出して土台を作り（2）、好奇心のスイッチを入れる（3）

### 4章 勉強後の緩和（2026-09-27 取り込み）

#### 概要
- 見出しは「成績の良い人は、勉強後に脳を使わない」。記憶を入れるだけでは足りず、「使える知識」に変えるカギは **勉強後の過ごし方**。ひとことで言えば「勉強後は脳を使わない活動をする」
- 脳には2つのモードがある。**集中モード**（1つの情報を必死に取り込む）と **緩和モード**（リラックスして、頭の中の複数の情報を結びつける）。緩和モードで知識が点から線になり、応用が利くようになる。成果は「集中した後に取る休息の質」で決まる
- 緩和テクは5つ。①報酬つきの昼寝 ②睡眠 ③運動 ④マインドフルネス瞑想 ⑤クロノタイプに逆らわずに休む

#### 要点（10個）
1. **勉強後は頭を切り離す**：終わった後に「また間違えた」「明日はあの単元を」と悩まない。脳をフル回転させ続ける人は、物知りでも知識が点のまま。例：「1919年にパリ講和会議」を集中モードで入れ、緩和モードで「日英同盟の解消」「中東問題」とつながっていく
2. **報酬つきの昼寝**（ジュネーブ大学）：①勉強後に昼寝 ②起きたら学んだ内容をテスト ③正解率が高ければごほうび。「賞品がもらえる」グループは正解率が高く、3か月後の抜き打ちテストでも高得点。ごほうびはお菓子・ゲーム・漫画など、ワクワクするもの。実験は90分だが、5〜10分の昼寝でも学習効率は上がる（10〜20分で認知機能・集中力、30分で疲労回復にも）
3. **ポモドーロ＋報酬つきの昼寝**：「25分集中→5分休憩」にこだわらず、「90分→20分」「40分→10分」など自分に合うリズムで。例：40分勉強 → 10分の昼寝 → 起きたら作っておいたテストを解き、高得点なら決めておいたごほうび。大事なのは集中の後に徹底的に脳を緩和させること
4. **ウェイクフルレスト**（眠れなくてよい）：暗い部屋で10分、目を閉じてボーッとする（何を考えてもよい）。小説を読んだ後にこれをしたグループは、ゲームをしたグループより記憶の定着率が10%高かった。学習直後のゲームは、脳が別の処理に使われて定着が下がる
5. **インターリービング・スリープ**（リヨン大学）：①勉強を **キリの悪い所**（問題の途中・解説のまん中）で止めて寝る ②起きたら続きから。「続きは？」という疑問が寝ている間の処理を進める。区切りよく止めると脳が「終わった」と思ってなまける。単語テストの成績が2倍。「1日の勉強はキリが悪いところで終える」
6. **寝る前5分でToDoリスト**（ベイラー大学）：翌日の勉強のタスクを具体的に全部書き出す。学習内容を思い出しやすくなり、眠りにつくまでが平均9分早くなった（睡眠薬と大差ない）。眠れない大きな原因は「翌日への不安」。頭の中だけでToDoを回さない
7. **睡眠学習は復習用ならアリ**（スイスの大学）：寝る前に聞いたオランダ語の音声を、眠った後にも流す → 起床後に単語を思い出す確率が10〜20%上がった（新しいことは覚えられない。まだ新しい研究）。やり方：①寝る前に学習用の音声を聞く ②眠って2〜3時間後に同じ音声が流れるようにする ③起きたらテスト
8. **勉強の前後に軽い運動**：勉強後に5分歩くだけで記憶が定着（ニュー・サウス・ウェールズ大学・2017年。顔写真の記憶テストで男性は約10%、女性は50%近く改善）。脳の働きを上げるなら中高強度（MVPA。早歩き〜ランニング、少し息が上がる）を10分（ウエスト・ロンドン大学。エアロバイク10分で分析力14%向上）。おすすめ：**勉強前に10分ランニング、勉強後に5分ウォーキング**

### 5章 上級者のやり方（2026-09-28 取り込み）

#### 概要
- 見出しは「ハイレベルの結果を叩き出す『上級者』のやり方」。2〜4章の3つの要点（①勉強の前はプランニングと音楽でモチベーションを上げる ②勉強中はアクティブラーニングで頭に叩き込む ③勉強の後は脳を休めて情報がつながるのを待つ）ができていれば、もう勉強法で悩まなくてよい。5章はその上を目指す人向けの7つ

#### 要点
1. **ひとりごと学習**
   - 勉強しながら、考えていることをぶつぶつ声に出す。自分の思考を声に出しながら小論文を書いた人は、成績が格段に良く、作業中の集中力も高かった
   - なぜ：**自己参照効果**（「自分」にからめたことほど記憶に残る）。自分の声を聞くと、思考が身近なものに変わる
   - 3つのパターン：**実況**（読みながら思ったことを実況する。聴こうとしなくてよい。著者は本を読みながら声に出して近所の森を歩く。人のいない所で）／**質問**（「テーマを本当に理解できたか？」「わからない用語はなかったか？」「段落の結論に同意できるか？」「そもそもどういう意味だったか？」。答えが出なくてもよく、質問にした時点で脳が解決に向けて動く。出なければ2章のメタ認知リーディングの質問を使う）／**要約**（セクションごとに、難しい言葉を自分の言葉で1文にまとめて声に出す。浮かばなければ「友人に説明するなら？」と考える）
2. **話しかけるつもり音読**
   - 音読は黙読より頭に入る。80個の単語を音読したグループは、黙読より成績が12%高い（時間はかかるが、それを補って余りある）
   - なぜ（プロダクション効果）：口や耳の運動機能を使ってアクティブになる／しっかり読まないと声に出せない／自己参照効果

   - なぜ：人の脳はコミュニケーション中に激しく働く（仲間の言葉を聞き逃すと死に直結した）。相手が聞いていなくても効果があったので、「いま友人に話しかけている」と考えるだけでよい
3. **マルチモーダル学習**
   - 視覚だけでなく、聴覚や運動感覚など多くの感覚を使うほど定着する
   - 1つのトピックを **複数のメディアで復習** する（例「冷戦の終結」：ノートを読み返す・教科書・学習サイト・ニュース動画・マインドマップでまとめ直す・いくつかのソースの問題を解く）
   - 著者のやり方：難しい本は音読し、**1章読み終えるたびに、まとめをスマホのレコーダーに吹き込む**（「最初のセクションには〇〇、次のブロックでは〇〇」）。本を読み終えて **しばらく時間を置いてから** その音声を聞いて復習すると、本の骨子だけが頭に残る。勉強なら、間違えた問題・忘れていた単語・その日の反省点を声で残す
4. **ジェスチャー法**
   - 体で表現しながら覚える（「manzana（リンゴ）」ならリンゴを口に運ぶ動作をしながら発音）。体を動かして学ぶと感覚・運動系も働き、情報が脳のいろいろな場所に保存され、思い出しやすい（1軒のスーパーより、あちこちにあるコンビニ）
   - 抽象的なことにも使える（積分なら細い線をしきつめる・薄い板を重ねる動き）。完璧でなくてよい
   - 思いつかなければ、**ただ体を動かすだけ** でもよい。ミシシッピ大学：ワーキングメモリのテストで、足を組み替える・机を叩く・貧乏ゆすりなど体をよく動かした子ほど成績が良かった。「集中力がない」と診断された子ほど効果が大きい
   - 動くのが苦手なら **ストレスボール**（注意力・文章力・コミュニケーション能力が改善）、ペン回し・消しゴムいじりでもよい。指先だけでも動かす
5. **勉強中にも運動**（見出しは目次から）
