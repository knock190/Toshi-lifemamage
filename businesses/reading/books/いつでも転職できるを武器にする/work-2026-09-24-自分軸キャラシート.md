# 自分軸キャラシート

作成日：2026年9月24日 ワーク元：「3 売れるキャラを確立する」

-----

## 軸となる一文

**人と仕組みの「見えない構造」を掘り当て、相手が言葉にできていない課題を形にする人**

-----

## 1\. ありがとうの声（メイン資質）

**「察して、期待の一歩先を出してくれてありがとう」**

資質を足すと、声はこう変わる：

  - ＋ 感情を受け止めて構造化 → 「現場の気持ちを分かった上で、本質的な課題を出してくれてありがとう」
  - ＋ 自走・用意周到 → 「言う前に動いて、しかも失敗させずに進めてくれてありがとう」

### 根拠となった実際の声

  - 「プログラミングができたら主体的にできそう」
  - 「気遣いができる」「自分で考えられそう」
  - 「そんなこともできるの？」（想定していなかった提案への反応）
  - 要求した機能だけでなく、言語化できていなかった機能を提案したことへの感謝

-----

## 2\. 資質の洗い出し

### フォースサイド（速く・ラクに・飽きずにできること）

| 資質 | 中身 |
| :-: | :-: |
| 観察力・洞察力 | 表情や言葉の選び方の変化に気づく |
| 人への好奇心 | 雑談から相手の価値観を探る |
| 問いを立てる力 | 「なぜこの仕組みなのか」を掘る |
| 要因分析・パターン抽出 | 成功・失敗の要因を構造化し抽象化する |
| 自走のループ | 課題設定 → 学習 → 実践を自分で回す |

対人でも仕組みでも、やっていることは同じ。 **「表に見えているものの裏側にある構造を知りたい」** が一本の芯。

### ダークサイド → 「いい意味で」変換

| コンプレックス | いい意味で | 実例 |
| :-: | :-: | :-: |
| 細かいことを詰めるのがつまらない | 全体構造から入る／手戻りを嫌い最初に設計する | あり |
| 相手の気持ちを考えすぎて合理的判断ができない | 人の感情を無視した施策を打たない／現場が本当に使うものを作れる | あり |
| 自分の損得勘定を考えがち | 利害構造を読める（相手の立場・望みを読む） | あり |
| 不安で嫌なイメージが浮かび行動が遅れる | リスクを事前に想定し、潰してから進める | あり |
| 出発点の価値観がズレたダメ出しにストレス | 判断の前提を大事にする／目的から考える | あり |
| やることが遅い（特に興味ないこと） | 興味の方向がはっきりしている | 保留（実例なし） |

### 心がざわつくこと（一番大事にしている資質）

  - **Flutter提案が受け入れられなかった件** → 悔しさの中身は「採用されなかった」ことより「調べて考えた中身を見てもらえなかった」こと
  - **自分より早く調べていい案を出されたこと** → 調べて考えることが自分の土俵である証拠
  - **飲み会で自分ばかり話してしまい落ち込む** → 「話せなかった」ではなく「聞けなかった」ことで落ち込む

→ 一番大事にしている資質は **「深く調べ構造を掴む力」** と **「相手を理解する力」** の2つ。 　Flutterの件は、この2つが噛み合わなかった瞬間だった。

-----

## 3\. コンボ（独自性の核）

### ① 相手の感情を受け止めながら、同時に原因を構造化する

アドバイスを急がず、**感情と解決策を50:50** で扱う。 「もしかしてこうだった？」と当てられるのは、聞きながら裏で構造を組んでいるから。

### ② 言われる前に課題を見つけ、リスクを潰しながら自走する

指示がなくても課題を立てる。不安を先回りのリスク想定に変換して進める。

-----

## 4\. 根拠（数字と名詞）

### 業務改善システム開発（社内DX推進）

自動車マニュアル作成部門の **10案件** で、依頼者が要件を言語化できていない状態から、背景・思い・業務内容を聞き込んで課題を定義。複数の解決策を提示し、依頼者と一緒に決める形でプロジェクトを開始。仕様が固まる前に最低限の形で走らせ、都度詳細を追加した。

  - 初版提供まで **約3週間**
  - **年間合計1,200時間** の工数削減（1件あたり約120時間）
  - 依頼者：各案件1名、自動車マニュアル作成部門

注：1,200時間は10案件の合計。先に自分から言うこと。

### AR受託開発

仕様変更に弱い設計だったため、顧客に早く触ってもらい検討時間を増やす目的で、共通化と依存関係の削減を軸に設計を変更。

  - 仕様変更の対応期間：**2週間 → 5日**（約1/3）
  - 顧客との検討サイクル：**2倍**

## 5\. 親の価値観と本来の資質の切り分け

### 幼少期に繰り返し言われたこと

  - 母親：相手に気を使って居心地よくする／周りをよく見る／要領よく考え行動する
  - 父親：資格を取れ

### 切り分け

**没頭できる（＝本来の資質）** 観察力・洞察力／人への好奇心／問いを立てて構造を掘る／要因分析・パターン抽出／自走のループ

**やらないと落ち着かない（＝親の価値観が乗っている）** 利害構造を読む／感情と解決策を50:50／用意周到／全体構造から入る

### 結論：残すが、動機を差し替える

  - ✗ 気を使わないと落ち着かない（**不安ドリブン**）
  - ○ この人の構造が知りたい・喜ばせたい（**好奇心ドリブン**）

**気遣いは目的ではなく、構造を知りたい好奇心の結果として出るもの。**

同じ行動でも、動機が不安側にあると消耗する。飲み会で落ち込んだ理由の7割が「気を使えなかった自分を責めている」だったのは、その稼働のサイン。
