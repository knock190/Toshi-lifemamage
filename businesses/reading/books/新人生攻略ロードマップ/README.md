### 第1章 そもそも「幸福度」ってなに？（2026-10-08 取り込み）

**概要**：ふわっとした「幸せ」を、脳内の4つの「幸せホルモン」（ドーパミン・セロトニン・オキシトシン・βエンドルフィン）が **バランスを保ったまま最大量出ている状態** と科学的に定義する章。どれか1つに偏ると満たされない（著者自身がドーパミンとβエンドルフィン過多で壊れかけた）。4つを同時に整える中心軸が **「他者への価値提供」** で、これが本の結論に近い。2章以降の「稼ぎ方のロードマップ」の土台。

**要点**（目次の見出しどおり）
- **幸福度は「科学的」に定義できる**：幸福感は脳内の化学物質（ホルモン・神経伝達物質）でもたらされる。だから測ったり高めたりできる。この先のロードマップの根幹なので、理解できるまで読み込む
- **4つの「幸せホルモン」**（本書では便宜上まとめて「幸せホルモン」と呼ぶ）
  - **ドーパミン**：目標達成の喜び・快感で人を行動へ駆り立てる。仕事で結果が出た・新しい挑戦・「何か良いことがありそう」のワクワク。注意＝衝動性を高め、追い求めすぎると依存（アルコール・ギャンブル）。著者は余命宣告まで飲み会を週8回
  - **セロトニン**：睡眠ホルモン（メラトニン）のもと。βエンドルフィンやドーパミンを制御して心を安定させる。栄養と日光で作られる → **毎日決まった時間に起きる・日光を浴びる・バランスの取れた食事・適度な運動**。偏ると、同じルーティンを淡々と回すだけで「落ち着いているのに満たされない」。土台として整える
  - **オキシトシン**：不安の軽減・共感・信頼感。家族や心を許せる相手・ペットとのスキンシップ、リラクゼーション施術で出る＝温かいつながりと安心の中で生まれる。偏ると居心地の良い所に留まり挑戦しなくなる（推進力にはなりにくい）
  - **βエンドルフィン**：ストレスに打ち勝つための「脳内麻薬」。必要だが、過剰だとうつ病・自殺のリスクや不安が上がる研究がある＝**アクセル**。徹夜の「自分は無敵」は限界が麻痺しているだけで、続けると休んでも落ち着けなくなる「限界をごまかして走る→壊れる」ループに入る。大事なのは、自分の負荷を把握して自分で調整できること、**無理を努力と勘違いしないこと。努力とは長く走れる状態を作ること**
- **バランスを保ったまま最大量分泌させる**：ドーパミンだけ（仕事に没頭）→セロトニン・オキシトシン不足。セロトニンだけ（規則正しいだけ）→退屈。オキシトシンだけ（人間関係だけ）→成長がない。βエンドルフィンとセロトニンのように一部トレードオフもある。「仕事で達成感を得る時間・規則正しい生活の時間・信頼できる人と過ごす時間」をすべて大切にする
  - 著者の例：大学生で起業し「稼ぐこと」最優先。売上・フォロワーの高揚は長続きせず次の刺激を求めた。ドーパミンとβエンドルフィン過多、セロトニンとオキシトシン不足。「すごいですね」で自分の価値を確かめる＝**達成基準が他人軸** になり、比較と嫉妬に悩む。不安をかき消すために働き、夜は飲み会、食事も荒れて過食で太った
- **［番外編］マズローの欲求階層説**：生理的→安全→社会的→承認→自己実現の5段階。下が満たされて上を求める。承認までの4つは「欠乏動機」、自己実現は「成長動機」で、真の幸福には両方が要る。ホルモンとの対応＝生理的（食事・睡眠）→セロトニン／安全・社会的（安心・つながり）→オキシトシン／承認（評価・成果）→ドーパミン／自己実現への負荷→βエンドルフィン。土台が弱いまま承認だけ追うとドーパミンが暴走する。著者は年商10億円で承認は満たされたが、社会的欲求と自己実現が欠けていた
- **［番外編］幸福度をパラメータで考える**：現実は「下から順に」ではなく、上に進んでも下が崩れる（著者は余命宣告で健康が揺らいだ）。そこで **健康（生理的）・金（安全）・人間関係（社会的）・成果（承認）・やりがい（自己実現）** の5項目をレーダーチャートにし、**五角形の面積が大きいほど幸福**。1つだけ突出しても面積は小さい。健康や時間の余白→セロトニン、人間関係→オキシトシン、やりがい→ドーパミン、適度な負荷→βエンドルフィン。自分が分かりやすいモデルで捉えてよい
- **他者への価値提供を重んじる（本の結論に近い部分）**：バランスを整える最も効果的な方法は、**ドーパミンの発生地点を「お金・比較・承認」から「他者の役に立つこと」に変える** こと。比較が基準だと、フォロワー数を抜かれただけで落ち込み、売上に執着して「何がやりたいか」より「何が稼げるか」になり燃え尽きる。価値提供が基準なら、人と比べず自分のペースで進め、役に立てた実感がドーパミン、適量のβエンドルフィン、信頼でオキシトシン、無茶をしないのでセロトニン＝**4つが同時に回る「続けるほど整う構造」**。論語の「徳」、近江商人の「三方よし」と同じ。道徳ではなく、最も合理的で再現性の高い戦略
- **幸福度を軽視した例と推奨する働き方**：①高級車を10台以上集めたガレージを持つIT経営者。訪ねてくる人がほとんどいない＝お金と自由があっても満たされない。②SNSで粘着してきたアンチは、実は成功した経営者で「若い著者が稼いでいるのが悔しく、俺のほうが上だと証明したかった」。比較でしか自分の価値を確かめられないと、相手を下げるしかなくなる。→ **1万人と浅く関わるより、100人に「あなたのおかげで人生が変わった」と言われる関わり方** のほうがオキシトシンが多く出る
- **進化的観点からの理由**：人は長い期間、親や仲間の助けがないと生きられないので、つながりたいと感じる脳に進化した。協力が生存に有利で「人の役に立つ＝快い」「感謝される＝嬉しい」が本能に組み込まれた（食料を分け合う人が信頼され、困ったときに助けてもらえる）。「縁起がいい」は本来「物事はつながり（縁）で成り立つ」という仏教の言葉。孤立や役に立たない生き方は虚しさや不安として表れる
- **章のまとめ**：本書では幸福度＝4つのホルモンのバランスと量。そのために重要なのが他者への価値提供。次章から「お金あり・幸せ」へ行く方法。この章は何度も読み返す

**要点の要約**：①幸せは4つのホルモンで説明できる（ドーパミン＝達成／セロトニン＝安定／オキシトシン＝つながり／βエンドルフィン＝踏ん張り）。②どれも偏ると壊れる。バランスを保ったまま量を増やす。③自分の状態は「健康・金・人間関係・成果・やりがい」の五角形で見られる。④4つを同時に整える軸は「他者への価値提供」。喜びの基準を、数字や比較から「誰かの役に立てたか」へ移す。⑤無理を努力と勘違いしない。努力は長く走れる状態を作ること

### 第2章 人生攻略ロードマップ 前編（2026-10-08 取り込み）

**概要**：幸福度を上げる土台として「4つの自由」（金銭・時間・精神・身体）を手に入れる道筋の前半。自由そのものはゴールではなく、幸福度が上がる行動に変えてはじめて意味がある。入口は金銭的自由（ほかの3つを押し上げる土台）。流れは「スキルで労働収入を増やす→資産性のある事業を作る→働かなくても入る仕組み」で、そのためのステップ1〜5を、5段階の目標を持って順に進める。どのステップでも「稼ぐ＝ありがとうの成績表」「信用を積む」が軸。

**要点**（目次の見出しどおり）
- **「4つの自由」を手に入れる**：①お金の心配をしなくていい ②時間の余裕 ③嫌なこと（ストレスを感じること）をしなくていい ④心身ともに健康。お金はホルモンのバランスを整える手段＝セロトニン（睡眠・食材）、オキシトシン（大切な人との時間）、ドーパミン（挑戦・学び）、βエンドルフィンに頼らない（外注・効率化）に使える。ステップ1〜5を順にやれば「複数の収入源・分散で不安が減る・仕組み化で労働を減らす・こけてもベーススキルでやり直せる」＝安定と自由が両方ある状態
- **5段階の目標を設定する**：①人生単位のビジョン（究極のゴール。魂が燃える「なんのために」）②長期（1年）③中期（半年。「今の自分の1.5倍」のちょっとキツめ）④短期（1ヶ月）⑤今日のToDo（数値化され達成が見える一歩＝ドーパミンを適量出す）。多くの人は「今日のToDo」しか持っていないので迷う。究極のゴールがあると比較や数字の沼に落ちにくい。著者の例＝個人が挑戦しやすい社会をつくる／Brainで100万ユーザー／新規登録を月5万人に／インフルエンサーに出品してもらう／インフルエンサー100人に営業メッセージ。今日のToDoが究極のゴールまでつながっているかが大事。死ぬときに「最高だった」と言える人生をゴールに
- **ステップ1 ゼロイチで稼ぐ経験を積む**
  - 必要収入を2段階で：「最低限の収入」（生活をギリギリまで切り詰めた生活費。外食などの贅沢はNG。下回るとセロトニンが阻害される）と「理想の収入」（多少の贅沢ができる額。わがままでよい）。ただし「毎日たくさんお酒・女性遊び」「FIRE」は理想から離れやすい（FIRE後に価値を感じにくい・孤立・張り合いがなくなる人も）。大事なのは五角形が大きく綺麗な状態を分かったうえで働き方を選ぶこと。例として最低限 月20万円・理想 月50万円
  - 稼ぎの内訳を数値に：最低限の月20万円（年240万円）を年利5%の運用でまかなうなら 4800万円が要る（税金は割愛）。残り30万円は3つの事業で（例：SNSのアフィリエイト 月20万円＋コンテンツ販売・電子書籍・コミュニティなどで月10万円）。どんぶり勘定でも「展望がある」ことに意味がある
  - 「最初の1円」：雇用される以外の稼ぎ方を一度経験する。金額より「誰かの財布を動かせた」自信。例＝不用品販売で5万円・ポイントサイトで5万円。時間を際限なくかけるのは本末転倒。ほかにクラウドワークスの初心者ライター案件（数千円〜1万円）、ポイ活・セルフバック（1〜3万円）、無料オファーのアフィリエイト（数百円〜数千円）
  - 目標は **5〜10万円**。それを「自己投資の種銭」にする。例＝字幕入れから始めて動画編集を学び大手の仕事・教育サービスへ進んだ人、ライター案件の稼ぎでプログラミングとライティングを学び単価が5倍になったスタッフ
- **ステップ2 ベーススキルを獲得し収益化する**
  - 選ぶ条件3つ：需要が供給を上回る（市場価値が高い）／リモート・独立しやすい／自分がやっていて楽しい。おすすめ＝プログラミング・動画編集・デザイン・アニメーション動画・広告の運用代行・SNSの運用代行・ライティング。令和6年版 労働経済白書では IT人材の「量」不足 85.2%・「質」不足 80.2%（読み取り。下の補足）。AIの時代も、使いこなす側・AI前提で設計できる人の需要は高まっている
  - 学習手順：①方向性を固める（「それを学んで何がしたいの？」。究極のゴールと噛み合うか）②無料サイトで最低限 ③有料スクール・教えてくれる人にお金を払って速度を上げる ④ポートフォリオなどアウトプット
  - なぜ有料か：著者は独学で1つのエラーに10〜20時間。9万円のスクールで、独学なら1〜2年かかる所を2ヶ月で身につけた。知識は「誰かが何年もかけた成果」を短時間で入れられる最強のレバレッジ。独学は「自覚のない無駄」。半年取れなかった初案件が、有料で学んで1〜2週間で取れた例。著者は今も年間2000万円ほどを自己投資
  - 習得のコツ＝継続：著者も初の単価100万円の案件まで2年ほど。「行動・学び・継続」。習慣化の方法は2つ＝**数字とチェックポイントのあるToDoリスト**（「ブログを書く」でなく「2000文字書く」、「勉強する」でなく「第3章まで読む」。達成したらチェック＝ドーパミン）と **朝活**（Brainサロンの毎朝6時のZoom。同じ時間にやる仲間がいると続く）。差は才能ではなく「当たり前の基準値」
  - お金を稼ぐとは：収入は価値提供の結果＝社会の成績表。ビジネスの本質は「どれだけ多くの人からありがとうを集められたか」。誰かの困りごとを解決する視点が、結局いちばん確実に収入になる
  - 仕事をとる方法：プログラミングは高額案件に「実務経験○年以上」があるので、まず転職して実務経験を積むのが最短。動画編集・ライティング・デザインは即独立もできる。ポートフォリオを作って企業やインフルエンサーにアプローチ。最初は収入より **信用を積む行動**（無償・低単価でも相手の課題解決を優先）。例＝Xで勝手にサムネイルを作って提案し案件に。採用されなくても、行動を投稿しておけば別の案件につながる
  - 仕事が取れないとき：「同じ価格で質を高く」か「同じ質で安く」。質＝要望に応える・速い・コミュニケーションが丁寧（報連相・レスポンス・リマインド＝相手の不安を消す）。例＝納期の3日前に進捗を一言
  - 目標は **月収20〜50万円**（最低限を下限に、理想まで）。「生活費程度ならスキルでいつでも稼げる」がセーフティネット。スキルは景気に負けない生涯資産で、最もコスパの良い保険
- **ステップ3 発信を始める**
  - なぜ：スキルを必要としている人を探すのが効率化する。まずはX・Instagramのライトな発信から
  - 3つのメリット：①報酬が相場より高くなる（発注者を選ぶ側になれる）②収益化の機会が増える（経験も売れる。例「動画編集のやり方を1時間3000円で教えます」。感謝される機会が増え、持続的なドーパミン。過去のダサい自分も誰かのコンテンツ）③ファン・同志が増える（価値観の合う人とつながりオキシトシン。事業づくりの孤独を防ぐ。著者のYouTube・ビジネス番組・10人の経営者と出資したシーシャ店もSNSの縁）
