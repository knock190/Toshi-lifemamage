### はじめに いま起きている3つの大きな変化
- 変化1 社会やビジネスが、いっそうインターネット化する
- 変化2 これから仕事で活躍できるのは、プロフェッショナルだけになる
- 変化3 会社と個人の関係が根底から変わる
