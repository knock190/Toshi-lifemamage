# 手順：ヘルスケアの記録（習慣データ GAS ＋ ショートカット＋オートメーション）

書き手：部門責任者（作業者が作り、チェック済み）。依頼票 2026-10-10-1。
**URL・トークンの実値はここに書かない**（公開リポジトリ）。`<UPDATER_URL>` `<UPDATER_TOKEN>` は更新役GASのもの、`<習慣GASのURL>` `<習慣GASのトークン>` は今の習慣のショートカット（DNB記録など）に入っているもの。どちらもとしやすが持っている。

## 何が貯まるか
習慣データに「ヘルスケア」シートができて、**1日1行**貯まる。

| 列 | 中身 |
|---|---|
| 日時 | 送った日時 |
| 対象日 | 前の日（`2026-10-09` の形） |
| 寝た時刻・起きた時刻 | **対象日の朝に起きた眠り**（その日の調子に効く眠り）。iPhone の睡眠スケジュールの記録から |
| 睡眠(分) | 起きた時刻 − 寝た時刻（GAS が計算） |
| 歩数・距離(km) | 対象日の合計 |
| 体重(kg) | 対象日にヘルスケアに入れた値（入れていない日は空欄） |

- 取れない値は空欄のまま送ってよい（エラーで止まらない）
- 同じ対象日を2回送っても行は増えない（上書き。空欄の値で前の値は消さない）。オートメーションを2本にしても大丈夫
- ショートカットの習慣の一覧（DNB・瞑想を選ぶ画面）には出ない
- 値はドライブにだけ置く。Git には書かない

## としやすの手順（1回だけ・15分くらい）

### 1. GAS に反映する（タップ1回。チャット側にリンクを作ってもらう：`handoff-chat-health.md` の「共有する文」を貼る）
`<UPDATER_URL>?token=<UPDATER_TOKEN>&action=update&target=habit&file=appsscript.json,habit_data.gs`
→ 「コードを反映しました」。確かめるなら `<習慣GASのURL>?token=<習慣GASのトークン>&action=ping` を開いて `"version":"2026-10-10.1"` が出れば OK
- 新しい許可は要らない（今と同じスプレッドシートを触るだけ）

### 2. ショートカット「ヘルスケア記録」を作る（iPhone のショートカットアプリ）
上から順にアクションを足す。（ ）の中は、そのアクションの結果に付ける名前（「変数を設定」で付ける）。

1. **日付**：「昨日」と入れる → **日付をフォーマット**：カスタム `yyyy-MM-dd`（→ `対象日`）
2. **ヘルスケアのサンプルを検索**：種類＝歩数／開始日＝昨日である → **統計を計算**：合計（→ `歩数`）
3. **ヘルスケアのサンプルを検索**：種類＝ウォーキング＋ランニングの距離／開始日＝昨日である／単位＝km → **統計を計算**：合計（→ `距離`）
4. **ヘルスケアのサンプルを検索**：種類＝体重／開始日＝昨日である／並び順＝開始日（新しい順）／上限＝1 → **ヘルスケアのサンプルの詳細を取得**：値（→ `体重`）
5. **ヘルスケアのサンプルを検索**：種類＝睡眠分析／終了日＝昨日である／並び順＝開始日（古い順）（→ `睡眠`）
   1. **リストから項目を取得**：最初の項目（`睡眠` から）→ **詳細を取得**：開始日 → **日付をフォーマット**：カスタム `yyyy-MM-dd HH:mm`（→ `寝た`）
   2. **リストから項目を取得**：最後の項目（`睡眠` から）→ **詳細を取得**：終了日 → **日付をフォーマット**：カスタム `yyyy-MM-dd HH:mm`（→ `起きた`）
6. **URLの内容を取得**：URL＝`<習慣GASのURL>`／方法＝POST／本文を要求＝JSON。項目はすべて「テキスト」で
   - `token`＝`<習慣GASのトークン>`
   - `action`＝`log`
   - `habit`＝`ヘルスケア`
   - `date`＝`対象日`
   - `sleep_start`＝`寝た`／`sleep_end`＝`起きた`
   - `steps`＝`歩数`／`distance_km`＝`距離`／`weight_kg`＝`体重`
7. （任意）**辞書の値を取得**：キー `message`（6 の結果から）→ **通知を表示**。自動で動いたかが分かる。うるさければ消してよい

### 3. 手で1回動かす（ヘルスケアの許可）
ショートカットをタップして実行 → 「ヘルスケアのデータへのアクセス」を聞かれたら、歩数・距離・体重・睡眠を **許可** → 「ヘルスケアを記録しました：2026-10-09 睡眠…・歩数…」と出れば成功。習慣データに「ヘルスケア」シートができている

### 4. 毎日自動で動かす（オートメーション）
ショートカットアプリ →「オートメーション」→「＋」→「時刻」
- **1本目：毎日 7:30**／「すぐに実行」→ ショートカット「ヘルスケア記録」
- **2本目：毎日 21:30**／「すぐに実行」→ 同じショートカット（保険）
- なぜ2本：iPhone がロックされている間は、ヘルスケアのデータを読めないことがある。朝に読めなかった日も、夜にもう一度送れば埋まる（同じ日は上書きなので行は増えない）

### 5.（任意・おすすめ）睡眠スケジュールをオン
ヘルスケアアプリ →「睡眠」→ 睡眠スケジュールをオン。腕の機器がないので、iPhone の睡眠の記録はこれをオンにしているときだけ残る。オフの日は寝た・起きたが空欄になる（エラーにはならない）

## うまくいかないとき
- 通知に `トークンが違います`：6 の `token` を、DNB記録のショートカットと同じ値にする
- 通知に `登録されていない習慣です: ヘルスケア`：1 の反映がまだ。1 をもう一度タップ
- 歩数が 0 や空欄：3 の許可で歩数を許可したか、設定 → ヘルスケア → データアクセスとデバイス → ショートカット で確かめる
- 睡眠に昼寝が入る：5 の「最後の項目」が昼寝になることがある。気になったら、5 の検索に「終了日が 昨日の 12:00 より前」を足す

## 確かめていないこと（2026-10-10）
- iPhone の実機での動き（アクションの名前は iOS の版で少し違うことがある）。としやすが 3 をやったら、秘書が「ヘルスケア」シートを読んで確かめる
- iPhone だけのときの睡眠分析の中身（「ベッドにいる」だけか「睡眠中」もあるか）。最初の1週間の行を見て、データ部が見直す
