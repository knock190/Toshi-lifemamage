# データ部の進め方（目的を実現するために何をするか）

書き手：部門責任者（依頼票 2026-10-11-1 で作業者が作り、部門責任者がチェックして確定）。「やること」の5（次に足す候補）は案で、選ぶのはとしやす

## 目的（2026-10-11 としやす決定）
物理世界の自分を、スマホ（と PC）を入り口にして、デジタル世界（だんご）と共有する。共有できれば、記録して、だんごと一緒に見て、管理できる。

## 考え方：共有は「4つの段」がそろって初めてできる

```
物理世界の自分 → ①入り口（スマホ・PC）→ ②置き場（ドライブ）→ ③だんごが分かる（目録）→ ④使う（朝の報告・ボード・分析）
```

- ①②だけでは「貯まっているだけ」。③だんごが「何が・どこに・いつから」あるかを知っていて、④実際に使って初めて共有になる
- 今のデータ部は①②を1つずつ作ってきた。足りないのは③（全体の目録）と、届いているかの見張り

## 入り口の型（新しいデータは、軽い型から選ぶ）

1. **自動**：iPhone のオートメーション → GAS → シート。としやすの手間は最初だけ（ヘルスケア・天気）
2. **1タップ**：ショートカットを押すだけ（DNB・瞑想・サプリ）
3. **書く**：夜の報告・ドキュメントに書く（体調・筆記開示・読書）。言葉でしか残せないもの
4. **ファイル書き出し**：アプリの CSV をドライブへ（お金）
5. **だんごが作る**：だんごの台帳から作る（タスクの数）。としやすの手間なし
6. **話す**（2026-10-11 ミーティング BM）：背面タップ等でショートカット → 声で話す → GAS → シート。その場で10秒で残す（考えメモ）。電波がないときは iPhone のメモに残す

## やること（順番つき）

1. **作りかけの3つを終わらせる**：天気・気圧（GAS）／体調・タスクの数のシート／睡眠の確かめ（10/13）。11/9 の分析の材料なので、これが先
2. **データの目録を作る**（③）：`mission.md` に「データの目録」の表を置く。1データ1行で「名前・領域・置き場所（ファイル名）・入り口の型・いつから・どのくらいの間隔・誰が使うか」。値は書かない。だんごのどの役割も、ここを見れば「としやすの何が分かるか」が分かる。新しいデータを足したら必ず1行足す
3. **届いているかを見張る**：自動のデータ（ヘルスケア・天気）は、秘書が毎朝の回で「前の日の行があるか」だけ見る。2日続けて来なければ朝の報告で1行（ショートカットが止まっていないか）。としやすの手間なし
4. **使い道を決めてから足す**：新しいデータは「何に使うか（朝の報告・ボード・分析のどれ）」を先に決める。使わないデータは集めない（集めても共有にならない）
5. **次に足す候補**（としやすが選ぶ。1つずつ）
   - 場所：家・職場・外にいた時間（iPhone の「到着・出発」のオートメーション → 自動。準備は最初の10分ほど）。体調・タスクと「家にいた日は動けない」の関係が見られる（9/29・9/30・10/7 の言葉）
   - 持ち物（2026-10-11 としやすが決めた。**服から試し始めた**＝`setup-belongings.md`）：何を持っていて、何を使ったか。物を「毎日使う（財布・鍵など。使った記録はとらない）／ときどき使う（服・キャンプ道具など。使ったかを見る）／消耗品（お金のデータから）」に分ける。一覧は写真からだんごが作り、使ったかは月1回の振り返り（○×）から始める。NFC タグなどお金がかかる方法は §6
   - スマホを使った時間：自動では取りにくい。取るなら週1回、画面の写しをドライブに置く形（としやすの手間あり）
6. **PC の入り口**は後回し：今は PC はチャットとドライブ。PC で使った時間などは、スマホの分が回り始めてから考える
7. **守る**：このリポジトリは公開。値・中身はドライブにだけ置き、Git には名前と傾向だけ。場所のデータは特に気をつける（家の位置は書かない）

## 2026-10-11 ミーティングで決まったこと（`meetings/2026-10-11-物理世界のデータ化.md`）
- 順番：①作りかけ3つ（10/13〜）→ ②考えメモ → ③場所。②③はとしやすが選んでから作る（BO）
- 考えメモの使い道（BN）：秘書が毎朝読み、やること → 振り分け（8-5）／アイデア → `company/backlog.md` に案で1行／気持ち → 何もしない（分析で体調と並べるだけ）。朝の報告には件数だけ。中身は Git にも朝の報告にも書かない
- やらないこと（BQ）：夜の報告に欄を足さない／スクリーンタイムは見送り／お金のかかる機器は使わない
