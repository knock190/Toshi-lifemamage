## 共有する文（としやすがチャット側に貼る）

```
だんごカンパニーのデータ部（Claude Code 側）から、習慣データGASの更新のお願いです。

【やりたいこと】
iPhone のヘルスケア（歩数・距離・体重・睡眠）を、毎日1行ずつ習慣データに貯めたい。そのために習慣データGASに「ヘルスケア」を足しました。反映のリンクを作ってください。

【Code 側で終わっていること】
・「GAS更新」フォルダの habit_data.gs を新しい版（2026-10-10.1）に入れ替えた
・前の版は habit_data_2026-09-27.2.gs に名前を変えて、前の版の置き場（habit_data_2026-09-25.1.gs と同じフォルダ）へ移した
・appsscript.json は変えていない。新しい許可も要らない（同じスプレッドシートを触るだけ）

【お願い】
1. 更新役GASで、target=habit を update するリンクを作ってください
   ?token=（更新役のトークン）&action=update&target=habit&file=appsscript.json,habit_data.gs
   → 私がタップします
2. 反映できたか、習慣データGASの ping で版が 2026-10-10.1 になったか確かめてください
3. うまくいかなければ rollback で戻してください

【新しい版で変わったこと】
・習慣「ヘルスケア」を追加（シートは最初の記録のときに自動でできる）
  見出し：日時／対象日／寝た時刻／起きた時刻／睡眠(分)／歩数／距離(km)／体重(kg)
・送り方：action=log, habit=ヘルスケア, date（yyyy-MM-dd。なければ昨日）, sleep_start・sleep_end（yyyy-MM-dd HH:mm）, steps, distance_km, weight_kg。空欄で送ってもエラーにならない
・同じ対象日を2回送ると、行を足さずに上書き（空欄の値で前の値は消さない）
・ヘルスケアは、ショートカットの習慣の一覧（list）と今週の回数（week）には出ない
・DNB・瞑想は今までどおり

このあと、iPhone のショートカット「ヘルスケア記録」とオートメーション（毎日 7:30・21:30）を作ります。手順は Code 側の departments/data/setup-health.md にあります。作るときに手伝ってもらえると助かります。
```
