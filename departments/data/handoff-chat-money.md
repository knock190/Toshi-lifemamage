## 3. CSV の形（チャットが置くもの）

- ファイル名：`YYYY-MM-DD_HHMM.csv`（置いた日時。1ファイルに何行あってもよい）
- 形式：UTF-8、1行目は見出し、カンマ区切り。変換なしの `text/csv`（Google 形式に変換しない）
- 列（`支出` シートと同じ順）：

```
日付,時刻,金額,払い方,分類,店・内容,元,入力した日,メモ
2026-09-28,12:30,500,PayPay,食費,コンビニ 昼ごはん,スクショ,2026-09-28, 
```

| 列 | 中身 | 決まり |
|---|---|---|
| 日付 | 払った日 `YYYY-MM-DD` | 必須 |
| 時刻 | `HH:MM` | 分からなければ空 |
| 金額 | 円の整数（カンマ・円マークなし） | 必須 |
| 払い方 | `PayPay`／`カード`／`現金` | 分からなければ空 |
| 分類 | `食費`／`日用品`／`趣味・交際`／`固定費`／`その他` | 必須 |
| 店・内容 | 自由 | カンマを含むときは `"` で囲む |
| 元 | `レシート`／`スクショ`／`文字` | |
| 入力した日 | `YYYY-MM-DD` | |
| メモ | 自由 | |

## 4. GAS にやってほしいこと

1. **取り込み**（関数例 `importCsv`）
   - 「お金の入力待ち」直下の `.csv`（Google 形式でない CSV）を古い順に読む
   - 見出し行を飛ばし、各行を `支出` シートの最後に足す。日付は日付として、金額は数値として入れる（`月の目標` の式が `SUMIFS` で日付と金額を見ているため）
   - 足し終えたファイルは `済` フォルダへ移す。**途中で失敗したファイルは移さない**（次の回にやり直す。二重に足さないよう、1ファイルの行は全部そろってから一度に `setValues` で足す）
   - 列の数が合わない・金額が数値でない行があれば、そのファイルは移さずに残し、ファイル名の頭に `エラー_` を付ける（黙って捨てない）
2. **時間の引き金**：`importCsv` を **1時間ごと** に動かす。引き金の設置で、としやすの操作はタップ1回までにする
3. **確かめ用**（あれば）：`ping`（版を返す）と、今月の件数だけを返す `count`（**金額は返さない**）

- ターゲット名の案：`money`（ソース名 `money_import.gs`）。スタンドアロンでよい（シートは ID で開く）
- 権限はとしやすのドライブとスプレッドシートだけ。共有・外への送信はしない

## 5. 終わったら確かめること

- テスト用の CSV を1つ置き（金額 `1`、メモ `テスト`）、引き金を待たずに `importCsv` を1回動かす → `支出` に1行入り、CSV が `済` に移ったら OK。テストの行は消す
- `月の目標` の 2026-10 の行は、日付が9月のテスト行では変わらない（正しい）
