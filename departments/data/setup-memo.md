## 目的
その場で考えたことを、10秒で声で残す。だんご（秘書）が毎朝読んで、やること・アイデアに振り分ける。

## 決めたこと（作る前の2点。決定 BU）
- 見張りの日数：**3日**（毎日書くものではないので、習慣より長くとる。最後の記録から3日あいたら朝の報告の見張りの1行に出す）
- 使い道（BN）：秘書が毎朝読む。やること → 夜の報告と同じく振り分け（8-5）／アイデア → `company/backlog.md` に案で1行／気持ち → 何もしない（分析で体調と並べるだけ）。朝の報告には **件数だけ**
- 中身は Git にも朝の報告にも書かない（ドライブだけ）。お金はかけない
- 使い方の候補（G13。強制しない・作業は増やさない）：何をやるか分からなくて不安なときは、「分かっていること／分からないこと」を声で書き出す。書き出すだけで、解決は求めない

## だんごがやること
- チャット側（GAS）：受け取った文字を、ドライブ「データ部/考えメモ」のシート（日時・本文）に足す。直し方は他のデータと同じ（`handoff-chat-*.md` の型）
- データ部：`mission.md` の「見張りの日数」と「完了の確認に使うデータ」に1行足す（シートができたら）
- 秘書：毎朝シートを読み、使い道のとおり振り分けて、件数を【事業の報告】に1行
