# 役目書：効果測定部

書き手：部門責任者（役目の変更はとしやすが決める）。部門の決まりは `company/rules.md` 8-8。部門責任者は `roles/business-head.md` に従う（事業責任者を部門責任者と読み替える）。

| 項目 | 内容 |
|---|---|
| 部門名 | 効果測定部 |
| 何のため | カンパニーの中で一番大事な「行動が効いたか」を測る。Ωは測った結果を受けて配分・方向性・事業の入れ替えを決める役に専念する |
| 役目 | 1. **行動ごとに測る形を作る**：「期待する変化／何で測るか／いつ見るか」を1行で決める<br>2. **貯まったデータを見て、変化を報告する**：2週ごとにΩへ<br>3. **「なりたい自分」の置き場を整える**：としやすの言葉が届いたら1か所にまとめる |
| 良し悪しの見方 | 測る形が事業の負担にならないか／2週ごとの報告が続いているか／Ωの配分の判断に使えているか |
| 開始 | 2026-09-26 |
| 状態 | 立ち上げ |

## 決まっていること（2026-09-25・26 としやす／Ωの決定。`company/decisions.md`）
- 効果測定は、Ωではなく効果測定部が持つ（自分の決定を自分で採点しないため。Ωは結果から方向性を考えることに集中する）
- 最初の形（2026-09-26 Ωの決定 J）：**DNB** と **筆記開示** の2つだけで試す
  - DNB 15分 → 期待する変化：作業記憶が伸びる／何で測るか：DNBの正解率（習慣データ）／いつ見るか：2週ごと（月曜5:00の回）
  - 筆記開示8分 → 期待する変化：不安・ストレスが減る／何で測るか：夜の報告の調子（◎○△）ととしやすの感覚／いつ見るか：2週ごと（月曜5:00の回）
  - サプリは体重・筋トレの記録ができてから測定を始める
- 見る間隔：月曜5:00の回で2週に1回（初回は 2026-10-06 の週の月曜の回）
- 「なりたい自分」：としやすの言葉はまだ届いていない。`company/principles.md` の「カンパニーで一番大事なのは効果測定」を土台にする。届いたらこのファイルにまとめる

## 置き場所
- データの中身（DNB の正解率・夜の報告の調子）は、データ部の「習慣データ」と `company/owner.md` から読む。効果測定部は Git に新しいデータを貯めない
