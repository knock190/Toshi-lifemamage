# 方向性

書き手：Ω。事業責任者はこれを基準に作業者の仕事をチェックする。

## 会社全体
- としやすが複数の事業を、止めずに同時に進められる状態をつくる
- 数を増やすより、全部が止まらずに進むことを優先する

## 事業ごと
### サプリ習慣化（supplements）
- 脳の活性化（クレアチン）と体の調子を整えるために、サプリごとの週の目安を毎週満たし続ける。期限はなく、続いている状態を見える化する（2026-09-27 としやす決定。筋トレが狙いなのはプロテインくらい）
- 記録の手間は増やさない方向で改善する

### お金（money）
- 貯金は「毎日がんばる」より「仕組みで勝手に貯まる」を作る。今は使ったお金の見える化と毎月の目標（5,000円から）を回し、そのあいだに先取り貯金と固定費の見直しを進める（2026-09-28 としやす決定）
- としやすの手間は「チャットに送る」だけ。細かい家計簿にはしない（分類は5つ、1円単位で合わせない）
- **金額・口座・カード・明細は Git に書かない**。台帳と報告は ○× と ％ まで

### 読書（reading）
- 読んで終わりにせず、行動に移す。冊数と「やってみた」の両方を積み上げる（としやすの決定）。迷ったら、行動につながる方を先にする
- 本のドキュメントはとしやすの言葉をもとにする。先生役は、読んだ本・としやすのワーク結果と、一般的な助言をはっきり分ける
- 「読む」は1日30分に収める。読む・ドキュメント化が30分を超えそうなら、量を減らして止めない方を選ぶ。としやすが選んだアクションプランの毎日の習慣は、30分の外で足してよい（2026-09-25 としやす承認）
