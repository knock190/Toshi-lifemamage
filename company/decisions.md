# 判断の記録

代表の判断と「なぜ」、Ωの予想との答え合わせを残す。Ωが代表のコピーに近づくための教材。
比べるのは **方向性**。施策が違っても方向性が同じなら一致。

書式：
```
## YYYY-MM-DD 件名
- Ωの予想：
- 代表の判断：
- なぜ：
- 一致：○／×（方向性で判定）
- 学び：
```

## 2026-09-23 仕組みづくりの方針決定
- 代表の判断：会社のように組織化する（代表・秘書・Ω・事業代表・作業者）
- なぜ：調査・計画・振り返り・改善を一人で回すと、同時に2つまでしか進められなかった。管理をだんごに任せれば、自分はオーダーと実行に集中して2つ以上回せる
- 代表の判断：事業の下は横断の部署を置かず、事業ごとの専門家にする
- なぜ：専門家にした方が思考も判断も速い。事業によっては横展開が逆に良くない可能性がある
- 代表の判断：Ωの目指す所は、代表と方向性が一致すること
- なぜ：方向性が合っていれば施策は何でもよい。方向性は、価値観による行動から生まれたやりたい事や課題に根ざしているから

## 2026-09-23 新規事業「読書」の立ち上げ
- 代表の判断：読書を事業として立ち上げる（ゴール・期限・かける時間は未定。Ωの案を待つ）
- なぜ：読んだ本をドキュメントとして残し、アクションプランを実行につなげたい。相談したとき、読んだ本から先生としてアドバイスがほしい
