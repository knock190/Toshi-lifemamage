# 判断の記録

としやすの判断と「なぜ」、Ωの予想との答え合わせを残す。Ωがとしやすのコピーに近づくための教材。
比べるのは **方向性**。施策が違っても方向性が同じなら一致。

書式：
```
## YYYY-MM-DD 件名
- Ωの予想：
- としやすの判断：
- なぜ：
- 一致：○／×（方向性で判定）
- 学び：
```

- としやすの判断：Ωの目指す所は、としやすと方向性が一致すること
- なぜ：方向性が合っていれば施策は何でもよい。方向性は、価値観による行動から生まれたやりたい事や課題に根ざしているから
